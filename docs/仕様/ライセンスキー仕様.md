# ライセンスキー仕様（TD1）

購入者に渡すキーの形式です。発行は `tools/keygen.py`、検証は
`app/taskdeck.html` の `TaskDeckLicense` が実装です。

## 形

```
TD1.<payload>.<signature>
```

- `TD1` … 形式の版
- `payload` … 下記 JSON を UTF-8 → base64url（パディングなし）
- `signature` … payload の署名（64 バイト）を base64url（パディングなし）

改行を含まない 1 行の文字列です。前後の空白と改行は、読み込むときに取り除かれます。

## payload

短くするため、キー名は 1 文字です。

```jsonc
{
  "n": "株式会社サンプル",   // 名義（表示される）
  "p": "business",         // プラン personal / business / site
  "s": 5,                  // 使用できる台数
  "i": "2026-08-21",       // 発行日
  "e": "2027-08-31",       // 任意 有効期限（省略すると無期限）
  "x": ["tax"]             // 任意 使える拡張の権利名
}
```

署名の対象は、この JSON を**キー名の昇順・区切りに空白なし・非 ASCII はそのまま**にした文字列です
（[パッケージ形式仕様](パッケージ形式仕様.md) と同じ規則）。

## 署名と検証

- 方式: ECDSA / P-256 / SHA-256、署名値は `r || s`（各 32 バイト）
- 秘密鍵は販売者だけが持ちます（`keys/private.json`）
- 製品には公開鍵だけが入ります（`const LICENSE_PUBLIC_KEY = "04…";` の 1 行）
- 検証は端末内で完結し、通信は発生しません

## 検証の順番と結果

1. 公開鍵が設定されているか → いなければ「まだ公開鍵が設定されていません」
2. `TD1.` で始まり、`.` で 3 つに分かれるか → 違えば「キーの形式が違います」
3. base64url として読めるか → 読めなければ「キーが途中で欠けているようです」
4. **署名が正しいか** → 合わなければ「このキーは正しくありません」
5. `e`（有効期限）が今日より前でないか → 過ぎていれば「有効期限が切れています」（日付つきで表示）

通ったキーだけが `taskdeck.license.v1` に保存されます。
保存されるのはキーの文字列だけで、中身は**起動のたびに検証し直します**。

## 有効期限の扱い

- 期限切れのキーは、起動時の検証で落ちます。アプリは評価版として動きます
- 判定は端末の日付を使います。端末の時計を戻せば延命できますが、そこは守っていません
  （買い切り販売が前提で、期限つきキーは例外的な用途のためです）

## 拡張の権利（`x`）

- 拡張の `manifest.entitlement`（省略時は `id`）が `x` に含まれていれば、その拡張は製品版として動きます
- 含まれていなくても拡張は動きます。ただし `manifest.trialLimit` の件数で制限されます
- あとからオプションを買った購入者には、**同じ名義で `--ext` を足したキーを再発行**します。
  購入者はキーを貼り替えるだけで、データはそのまま残ります

## 発行のしかた

```bash
python3 taskdeck/tools/keygen.py issue --name "株式会社サンプル" --plan business --seats 5
python3 taskdeck/tools/keygen.py issue --name "株式会社サンプル" --plan business --seats 5 --ext tax
python3 taskdeck/tools/keygen.py issue --name "個人事業主 山田" --plan personal --expires 2027-03-31
python3 taskdeck/tools/keygen.py verify "TD1.…"
```

発行したキーは `keys/issued.csv` に控えが残ります（発行日・名義・プラン・台数・期限・拡張・メモ・キー）。

## 守っている範囲

**守る**: 秘密鍵を持たない第三者が、有効なキーを作ること。
**守らない**: 購入者が HTML を書き換えて検証を無効にすること。

配布物がテキストである以上、後者は技術的に防げません。
使用許諾契約書で再配布・改変配布を禁じることで対応します。
