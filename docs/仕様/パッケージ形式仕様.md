# 拡張パッケージ形式仕様（taskdeck-package/1）

拡張の配布ファイル `.tdpkg` の形式です。作る側は `tools/pkg.py`、
読む側は `app/taskdeck.html` の 6.5 節が実装です。

## ファイル

拡張子 `.tdpkg`、中身は UTF-8 の JSON。

```jsonc
{
  "format": "taskdeck-package/1",
  "manifest": {
    "id": "tax",                    // 必須 [a-z0-9][a-z0-9-]{1,30}
    "name": "確定申告データ管理",     // 必須 表示名
    "version": "1.0.0",             // 必須
    "apiVersion": "1",              // 必須 対応する拡張 API の版
    "vendor": "〔販売者名〕",         // 任意
    "description": "…",             // 任意
    "entitlement": "tax",           // 任意 ライセンスキーに書く権利名（既定は id）
    "trialLimit": 30                // 任意 権利が無いときに拡張へ伝える上限
  },
  "code": "api.registerView({ … })", // 必須 実行される JavaScript
  "signature": "MEUCIQ…"            // 必須 base64url（64 バイト）
}
```

## 署名

対象は **`{code, manifest}` を並び順固定の JSON にしたもの**です。`format` と `signature` は含みません。

並び順固定の規則（Python の `json.dumps(..., sort_keys=True, ensure_ascii=False, separators=(",", ":"))` と
JavaScript の `canonicalJson()` が一致するように定めています）:

1. オブジェクトのキーは**コード単位で昇順**に並べる
2. 区切りは `,` と `:`。空白を入れない
3. 非 ASCII 文字はそのまま出す（`\uXXXX` に置き換えない）
4. 配列の順序は保つ

この文字列を UTF-8 にし、**ECDSA / P-256 / SHA-256** で署名します。
署名値は `r || s`（各 32 バイト、合計 64 バイト）を base64url（パディングなし）にしたものです。

> Python と JavaScript で 1 バイトでも出力が違うと、正しいパッケージが弾かれます。
> `tests/test_package.py` が、日本語・改行・引用符を含むデータで両者の出力を突き合わせています。

## 読み込みの順番

アプリは次の順で確認し、1 つでも通らなければ**実行しません**。

1. JSON として読めるか
2. `format` が `taskdeck-package/1` か
3. `manifest` の必須項目（`id` / `name` / `version` / `apiVersion`）があるか
4. `id` が `[a-z0-9][a-z0-9-]{1,30}` に合うか
5. `apiVersion` が本体の対応版と一致するか
6. `code` と `signature` が空でないか
7. **署名が公開鍵で検証できるか**
8. （ここまで通ったら）`new Function` で実行

検証は**読み込み時と、起動のたび**に行います。保存後に書き換えられていても検出されます。

## 同じ id のパッケージを読み込んだとき

置き換えになります（更新）。拡張が保存したデータ（`taskdeck.ext.<id>.v1`）は**残ります**。
古い版のデータを新しい版が読めるようにするのは、拡張の責任です。

## 作りかた

```bash
python3 taskdeck/tools/pkg.py build extensions/tax          # 署名して dist/ に出力
python3 taskdeck/tools/pkg.py verify dist/tax-1.0.0.tdpkg   # 署名の確認
python3 taskdeck/tools/pkg.py info   dist/tax-1.0.0.tdpkg   # 中身の確認
```

`build` に必要なのは、`manifest.json` と `main.js` が入ったフォルダと、
`keys/private.json`（`keygen.py init` で作られる秘密鍵）です。

## 大きさの目安

`code` は JSON の文字列として入るため、素の JavaScript より少し大きくなります。
確定申告拡張（約 650 行）で、パッケージは約 35 KB です。

## 表示されるエラー

| 文言 | 原因 |
|---|---|
| これは TaskDeck の拡張パッケージではないようです。 | `format` が違う |
| この拡張は TaskDeck の拡張 API v… 向けです。 | `apiVersion` が本体と合わない |
| 署名が確認できませんでした。 | 署名が無い・壊れている・別の鍵で署名されている・中身が書き換えられている |
| 読み込み中にエラーが起きました: … | `code` の実行時に例外。拡張は自動的に停止する |
