# QA 手順

`core/` は `npm test`（153 件）で機械検証済み。
ここでは DOM / WebAudio / WebCodecs に依存し自動化しにくい部分の確認手順をまとめる。

## 0. 事前準備

```bash
npm test     # 全件パスすること
npm start    # http://localhost:8080
```

テスト素材は次の 4 種類を用意する。

| # | 素材 | 目的 |
|---|---|---|
| A | 会話 1〜3 分 / MP4(H.264+AAC) | 標準ケース |
| B | 音声トラックなしの動画 | 映像のみモードへの縮退 |
| C | ブラウザ録画由来の WebM（`duration` が未確定なもの） | 尺の解決 |
| D | 30 分以上の長尺 | 性能・メモリ |

---

## 1. 素材読み込み（AC-01）

- [ ] D&D とファイル選択の両方で読み込める
- [ ] 素材パネルに ファイル名 / 尺 / 解像度 / fps / 音声有無 が表示される
- [ ] 素材 C で尺が `Infinity` にならず正しい値になる
- [ ] 動画以外のファイルを渡すとエラートーストが出て、状態が壊れない
- [ ] 0 バイトのファイルで「ファイルが空です」と表示される
- [ ] 2GB 超のファイルで確認ダイアログが出る

## 2. 解析（AC-02）

- [ ] 進捗ラベルが「音声をデコード中 → 包絡 → 発話区間 → フレーム → シーン」と進む
- [ ] キャンセルを押すと即座に止まり、「キャンセルしました」が表示される
- [ ] 素材 B で「音声トラックをデコードできませんでした」と案内され、映像解析は続行する
- [ ] タイムラインに波形・クリップ・発話区間・シーン境界・字幕が描かれる
- [ ] 素材 D で解析が完了する（フレーム間隔が 0.5 秒へ自動的に粗くなる）

## 3. 字幕（AC-03 / AC-04）

- [ ] 「字幕を自動生成」で発話区間ぶんのキューが生成される
- [ ] STT 未設定時、テキストは空欄で「要入力」バッジが付く（**架空の文章が入らないこと**）
- [ ] テキストを入力するとバッジが消え、件数表示の「未入力」が減る
- [ ] 時刻欄に不正な値を入れるとエラートーストが出て、元の値へ戻る
- [ ] SRT / VTT を取り込める。壊れた行はスキップされ件数が報告される
- [ ] 全体シフト（±0.5 秒）が効き、0 秒より前にはならない
- [ ] 「未入力へ移動」でその行までスクロールしフォーカスが当たる
- [ ] `Alt + ↑ / ↓` で行間を移動できる
- [ ] **1,000 件以上**の SRT を取り込んでもスクロールが滑らか（可視範囲のみ描画）
- [ ] 1 キューに 5,000 文字入れても入力が固まらない

### 外部 STT を設定する場合

- [ ] API キー未入力で実行するとその旨のトーストが出る
- [ ] 認証エラー時、原因が日本語で表示され「タイムコードのみ生成する」導線が出る
- [ ] キャンセルが効く
- [ ] リロード後に API キーが**残っていない**こと

## 4. 編集（AC-05）

- [ ] 「自動カットを適用」で尺が縮み、削減率がトーストとパネルに出る
- [ ] 倍速モードでは尺が縮むが映像は全区間残る（タイムラインが黄色で表示される）
- [ ] スライダー操作中にコントロールが作り直されない（つまみを掴んだまま動かせる）
- [ ] `S` で分割できる。クリップの端では「この位置では分割できません」と出る
- [ ] クリップのチェックを外すと尺が減り、プレビューでもその区間が飛ばされる
- [ ] 発話が検出されなかった素材では素材全体が 1 クリップとして残る

## 5. 音声（AC-06）

- [ ] 正規化 ON/OFF で音量が変わる
- [ ] ピークが高い素材で「クリップ回避を優先」の説明が出る
- [ ] BGM を読み込み、発話中に BGM が下がる（ダッキング）
- [ ] フェードイン / アウトが冒頭と末尾で効く
- [ ] 短い素材（3 秒未満）でもフェードが尺を食い潰さない

## 6. サムネイル（AC-07）

- [ ] 「候補を自動抽出」で 8 枚の候補が生成され、進捗が出る
- [ ] 候補をクリックするとプレビューが切り替わる
- [ ] 見出しを長くしても自動で縮小・折返しされ、枠からはみ出さない
- [ ] 「字幕から見出しを提案」— 字幕が無い場合はエラートーストが出る
- [ ] PNG が 1280×720 で保存される
- [ ] 縦動画（9:16）でも黒帯付きで正しく出力される

## 7. キャプション（AC-09）

- [ ] 4 プラットフォームすべてで生成でき、文字数カウンタが上限を超えない
- [ ] 字幕 0 件でも尺情報で生成され、その旨の案内が出る
- [ ] YouTube のみチャプターが含まれる
- [ ] コピー・テキスト保存が動く

## 8. 書き出し（AC-08）

- [ ] 書き出しパネルに実際の出力形式（MP4 / WebM）が表示される
- [ ] 進捗 % と残り時間が更新される
- [ ] キャンセルすると即座に止まり、その旨が表示される
- [ ] 出力動画で **字幕が焼き込まれ、カットと音量調整が反映されている**
- [ ] プレビューと出力の見た目が一致する
- [ ] SRT / WebVTT / プロジェクト JSON が保存できる
- [ ] プロジェクト JSON を読み込むと編集内容が戻る（素材の再選択を促される）

## 9. アクセシビリティ（AC-11）

- [ ] `Tab` のみで全機能へ到達できる
- [ ] ダイアログで `Esc` が効き、閉じると元の要素へフォーカスが戻る
- [ ] ダイアログ内で `Tab` がループする（外へ出ない）
- [ ] スクリーンリーダー（NVDA / VoiceOver）で進捗・完了・エラーが読み上げられる
- [ ] タイムラインにフォーカスして矢印キーで移動でき、現在位置が読み上げられる
- [ ] ブラウザ 400% ズーム / 幅 320px で横スクロールが発生しない
- [ ] OS の「視差効果を減らす」設定でアニメーションが無効になる

## 10. 永続化と復旧（AC-12）

- [ ] 編集後にリロードすると内容が復元され、素材の再選択を促される
- [ ] `Ctrl+Z` / `Ctrl+Shift+Z` が 50 段まで動く
- [ ] プライベートブラウジング（localStorage 不可）でも起動でき、「自動保存できません」と表示される
- [ ] 再生中 / 書き出し中にタブを閉じようとすると確認される

---

## 既知の非対応

- 書き出し時間はおおむね出力尺の 1〜2 倍（フレーム取得のシークが支配的）。
  さらなる高速化には MP4 デマルチプレクサ + `VideoDecoder` が必要。
- WebCodecs 非対応の環境では `MediaRecorder` による実時間書き出しへ退避する
  （この場合のみ、画面ロックやアプリ切り替えで成果物が壊れうる）。
- 音声認識テキストは外部 STT 設定時のみ。
- OPFS に保存する素材は 600MB まで。超える場合は復帰時に選び直しが必要。

## 11. スマートフォン（v2 で追加）

実機は iPhone (Safari) と Android (Chrome) の両方で確認する。
エミュレータでは WebCodecs・メモリ上限・共有シートの挙動が再現しない。

### 導入

- [ ] ブラウザのメニューから「ホーム画面に追加」ができる
- [ ] ホーム画面のアイコンから起動するとアドレスバーが出ない（standalone）
- [ ] 機内モードでも起動して編集画面が出る
- [ ] ノッチ／ホームバーに UI が隠れない（縦・横の両方）

### 操作

- [ ] 縦持ちで全タブへ到達でき、タブ列が常に画面内にある
- [ ] すべてのボタンが指で押せる（44px 以上）
- [ ] 入力欄をタップしても画面が自動ズームしない
- [ ] 日本語入力の変換中に候補が確定していない状態で反映されない
- [ ] ダイアログが下から出て、親指の届く位置にボタンがある
- [ ] トーストが画面を覆い尽くさない（最大 2 件）

### 素材

- [ ] 写真アプリから動画を選べる（`accept="video/*"`）
- [ ] iPhone で撮影した 4K/HEVC 動画を読み込める（読み込めない場合は理由が出る）
- [ ] 10 分以上の素材で解析が完了する（タブが落ちない）
- [ ] アプリを切り替えて戻っても編集内容が残る
- [ ] ブラウザを完全に終了して再度開くと、**素材ごと**復帰する

### 書き出し

- [ ] 書き出し方式に「高速・再生に依存しない」と表示される（WebCodecs 経路）
- [ ] 書き出し中に画面が消灯しない
- [ ] 書き出し中にアプリを切り替えて戻っても、成果物が壊れていない
- [ ] 出力が MP4 で、写真アプリと SNS アプリの両方で再生できる
- [ ] 「共有」から TikTok / Instagram / X へ直接送れる
- [ ] サムネイル PNG・キャプションも共有できる
- [ ] 容量不足時にエラーの理由が表示される
