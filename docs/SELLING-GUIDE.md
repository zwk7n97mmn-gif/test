# 販売のはじめかた（販売者向け）

**BOOTH での販売**を想定した手順です。上から順にやれば、その日のうちに売り始められます。
所要時間はおよそ 1〜2 時間です。サーバーは要りません。

> ℹ️ 自分のサイトで売る場合は、`sales.json` の `channel` を `own-site` にしてください。
> 確認する項目が切り替わります（特商法の掲載などが増えます）。

---

## 0. 何がどこにあるか

```
taskdeck/
├── app/taskdeck.html        製品そのもの（これを売ります）
├── extensions/tax/          オプション「確定申告データ管理」のソース
├── landing/
│   ├── BOOTH商品説明.md     BOOTH の商品説明欄に貼る文面
│   └── index.html           自分のサイトで売る場合の販売ページ（BOOTH なら使いません）
├── docs/
│   ├── MANUAL.md            購入者向けの使い方（ZIP に同梱されます）
│   ├── README-FOR-BUYER.txt 開封時に最初に読んでもらう案内
│   ├── SELLING-GUIDE.md     この文書（売り始めるまで）
│   ├── OPERATIONS.md        売り始めた後の運用（注文対応・問い合わせ・鍵の保管）
│   └── MAIL-TEMPLATES.md    納品・サポートのメール文面
├── legal/                   使用許諾契約書・特商法表記・プライバシーポリシー
├── tools/
│   ├── preflight.py         売り始める前の確認（抜けを機械で見つける）
│   ├── keygen.py            ライセンスキーの発行・控えの一覧・作り直し
│   ├── pkg.py               拡張パッケージの署名
│   └── build.sh             配布用 ZIP の作成（本体＋拡張）
├── keys/                    秘密鍵と発行台帳（自分だけが持つ。公開厳禁）
└── sales.json               どこで売るか（booth / own-site）
```

---

## 1. 鍵を作る（最初に一度だけ）

```bash
python3 tools/keygen.py init
```

これで次の 2 つが起きます。

- `taskdeck/keys/private.json` に**秘密鍵**ができる
- `app/taskdeck.html` に**公開鍵**が埋め込まれる

> **秘密鍵は必ずバックアップしてください。**
> 失うと、以後キーを発行できなくなります。作り直すと、それまでに売ったキーが
> すべて無効になります（購入者の手元で「正しくありません」と出ます）。
> `keys/` は `.gitignore` によって Git に入りません。パスワード管理ソフトや
> 暗号化した外部メディアなど、リポジトリの外に保管してください。

公開鍵は配布物に入りますが、これは公開して問題ありません。
公開鍵だけではキーを作れないため、配布物を解析されてもキーは偽造されません。

---

## 2. 商品説明を用意する

`landing/BOOTH商品説明.md` に、そのまま貼れる文面があります。
〔　〕を自分の情報に置き換えてください。

> 🚨 **「ライセンスキーは後から届く」ことを必ず書いてください。**<br>
> キーは手で発行して送ります。先に伝えていないと「キーが来ない」という
> 問い合わせが必ず来ます。`preflight` がこの一文の有無を見ています。

**待たせても成立する理由**は、キーが無くても本体が動くからです。

| 購入直後 | キーが届いた後 |
| --- | --- |
| ZIP をダウンロードしてすぐ使える | ライセンス名義が入る |
| タスク管理はすべて使える | オプションの体験版制限が外れる |

スクリーンショット（`landing/assets/`）は商品画像として使えます。

> ℹ️ `landing/index.html` は、自分のサイトを持つ場合の販売ページです。
> BOOTH で売るなら使いません。

## 3. BOOTH に出品する

1. [BOOTH](https://booth.pm/) でショップを作る（pixiv アカウントが要ります）。
2. **プランごとに商品を分けて**登録する。バリエーションではなく別商品にします。
   説明も価格もプランごとに違うためです。
3. 商品種別は**ダウンロード商品**。5 章で作る ZIP をアップロードします。
4. 商品説明に、2 章の文面を貼る。
5. 公開したら、商品ページの URL を `sales.json` の `product_urls` に控える。

| 商品 | 価格の目安 |
| --- | --- |
| TaskDeck パーソナル（1台） | 3,000〜4,000円 |
| TaskDeck ビジネス（5台） | 12,000〜15,000円 |
| TaskDeck サイトライセンス | 40,000〜60,000円 |
| TaskDeck 確定申告オプション | 6,000〜8,000円 |

> ⚠️ **手数料と特商法の扱いは、申し込む前に BOOTH の公式で確かめてください。**<br>
> どちらも変わります。このファイルの数字は目安です。

注文が入ると BOOTH から通知が来ます。それを見て次の 4 章でキーを発行します。

> 💡 自動化したくなったら、通知から `keygen.py issue` を呼ぶ形にできます。
> ただし**最初は手作業で十分**です。1 件あたり 1 分もかかりません。

## 4. 注文が入ったらキーを発行する

```bash
python3 tools/keygen.py issue --name "株式会社サンプル" --plan business --seats 5 --note "注文番号 1234"
```

- `--plan` は `personal` / `business` / `site`
- `--seats` は使用できる台数
- 期間限定にするなら `--expires 2027-08-31`

発行したキーは `keys/issued.csv` に控えが残ります。
出力された `TD1.〜` の 1 行を、**BOOTH のメッセージ**で購入者に送ります。
文面は `docs/MAIL-TEMPLATES.md` にあります。

> ⚠️ `--note` に**注文番号を必ず入れてください**。
> 後から「この人に何を売ったか」を引けるのは、控えのメモだけです。

発行したキーが有効かどうかは、いつでも確認できます。

```bash
python3 tools/keygen.py verify "TD1.…"
```

発行した控えは、後から探せます。

```bash
python3 tools/keygen.py list                   # これまでに発行した分を一覧する
python3 tools/keygen.py list --find "サンプル"   # 購入者・メモ・発行日で探す
python3 tools/keygen.py reissue --row 12       # キーを無くした人に、同じ内容で作り直す
```

> ⚠️ **作り直しても、前のキーは使えなくなりません。**
> アプリは通信しないため、発行済みのキーを後から止める手段がありません。
> 詳しくは [OPERATIONS.md](OPERATIONS.md) にあります。

## 4.5 オプション（拡張）を売る

本体とは別に、拡張パッケージを単品で売れます。手順は本体とほとんど同じです。

```bash
bash tools/build.sh
# → dist/taskdeck-1.0.0.zip        本体
# → dist/taskdeck-tax-1.0.0.zip    オプション「確定申告データ管理」
```

注文が入ったら、その購入者の**新しいキーを発行し直します**。

```bash
python3 tools/keygen.py issue --name "株式会社サンプル" --plan business --seats 5 --ext tax
```

購入者は、届いたキーを「ライセンス」画面で入れ替えるだけです。
記録済みのタスクや仕訳はそのまま残ります。

| 場面 | 発行するキー |
|---|---|
| 本体だけ | `--ext` なし |
| 本体＋確定申告 | `--ext tax` |
| あとから確定申告を追加購入 | 同じ購入者に `--ext tax` を付けて再発行 |

拡張は、キーが無くても評価として動きます（確定申告なら仕訳 30 件まで）。
「まず入れてもらって、続けたくなったら買ってもらう」流れを作れます。

拡張を新しく作るときは `extensions/` に置いて `python3 tools/pkg.py build extensions/<id>` を実行します。
書き方は `taskdeck-docs/docs/開発/拡張の作り方.md` にまとめてあります。

## 5. 配布用 ZIP を作る

```bash
bash tools/build.sh
```

`dist/taskdeck-1.0.0.zip` ができます。中身はアプリ本体・マニュアル・
使用許諾契約書・はじめにお読みくださいの 4 点です。
公開鍵が未設定のときや、テストが通らないときは、途中で止まって配布物を作りません。

この ZIP を、BOOTH の商品に**ダウンロードファイルとしてアップロード**します。
配信は BOOTH がやってくれるので、置き場を自分で用意する必要はありません。

> ℹ️ **ZIP は全員同じものです。** 個別なのはライセンスキーだけなので、
> 版を上げたときはアップロードし直すだけで済みます。

## 6. 法務

| 書類 | BOOTH で売る場合 |
| --- | --- |
| **特定商取引法に基づく表記** | **BOOTH 側の設定**で行います。個人の住所の扱いも含め、BOOTH の案内に従ってください |
| **プライバシーポリシー** | `legal/PRIVACY.md` を自分の情報に。ショップの説明か商品説明からリンクします |
| **使用許諾契約書** | `legal/EULA.md` を自分の情報に。ZIP に同梱されます |

> ⚠️ **自分のサイトで売る場合は話が変わります。**<br>
> 氏名の掲載は省略できません。住所と電話番号は「請求があれば遅滞なく開示します」で
> 代替できる場合がありますが、条件があります。消費者庁の特定商取引法ガイドを確認してください。

## 7. 売る前の最終確認

**まず機械に見てもらいます。**

```bash
python3 tools/preflight.py
```

残っているものを並べてくれます。全部 OK になるまで直してください。

| 見ているもの |
| --- |
| 公開鍵がアプリに入っているか／秘密鍵があるか |
| 秘密鍵が Git に入っていないか（🚨 いちばん危ないところ） |
| 〔　〕の置き換えが済んでいるか（販売ページ・法務ページ） |
| 見本のアドレス（`example.com` など）が残っていないか |
| 決済リンクが入っているか／リンクが切れていないか |
| 販売ページから使用許諾契約書・特商法表記・プライバシーポリシーへ辿れるか |
| テストが通るか／配布 ZIP を作れて一式が入っているか |

`--quick` を付けると、テストと ZIP 作成を飛ばして速く見られます。

**その後、自分の目で確かめるもの**（機械では見られません）。

- [ ] 自分で商品ページを開き、購入手続きの画面まで進めることを確かめた
- [ ] 発行したキーが、実際に `TaskDeck.html` で登録できることを自分で確かめた
- [ ] BOOTH から ZIP が落ちてきて、中の HTML が開くことを確かめた
- [ ] 送る文面に、キー・使い方・問い合わせ先が入っている
- [ ] BOOTH 側の特定商取引法に基づく表記が、実態と合っている
- [ ] オプションを売るなら、拡張つきのキーで実際に制限が外れることを確かめた
- [ ] 秘密鍵をリポジトリの外にバックアップした

売り始めた後の運用は [OPERATIONS.md](OPERATIONS.md) にまとめてあります。

## 価格の考えかた

買い切りのデスクトップ向けツールとしては、次のあたりが置きやすい値段です。

| プラン | 目安 | 想定 |
|---|---|---|
| パーソナル（1台） | 3,000〜4,000円 | 個人。月額サービスを避けたい層 |
| 確定申告オプション | 6,000〜8,000円 | 本体購入者への追加販売。単価を上げやすい |
| ビジネス（5台） | 12,000〜15,000円 | 小さなチーム。部署単位の購入 |
| サイトライセンス | 40,000〜60,000円 | 法人一括。情報を外に出せない現場 |

この製品の強みは「サーバーに置かない・通信しない・買い切り」です。
月額のクラウド型と機能数で競うのではなく、
**外部にデータを預けられない現場**（士業・医療・自治体・製造業の現場など）に向けて説明すると通りやすくなります。

## 値上げ・改訂をするとき

- 価格は BOOTH の商品ページで直します。
- アプリを直したら `VERSION=1.1.0 bash tools/build.sh` で新しい ZIP を作り、
  BOOTH の商品にアップロードし直します。**購入済みの方も新しいファイルを落とせます。**
  案内する相手は `python3 tools/keygen.py list` で調べられます。
- 公開鍵は変えないでください。変えると発行済みのキーが無効になります。
