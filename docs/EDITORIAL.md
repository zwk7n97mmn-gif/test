# 編集方針

このアカウントの価値は「面白さ」ではなく「間違っていないこと」に置いています。
心理学は再現性の問題を抱えた分野で、SNS で人気の「心理学の豆知識」には、
すでに否定された研究が大量に混ざっています。ここではそれを載せません。

## 採用の基準

1. **査読付き論文に基づくこと。** 全 180 件に出典を付けています。
2. **追試で支持されていること。** 単発の派手な研究より、メタ分析や
   複数の独立した追試があるものを優先します。
3. **効果量を誇張しないこと。** 「人生が変わる」ではなく「わずかに上がった」
   と書きます。小さい効果は小さいと書きます。
4. **行動に移せること。** 知識で終わらず、明日試せる形にします。

## 意図的に除外したもの

人気があるが、追試の失敗や重大な批判があるため採用しませんでした。

| 俗説 | 除外理由 |
|---|---|
| パワーポーズで自信とホルモンが変わる | 大規模追試でホルモン効果は再現されず。原著者の1人が主張を撤回 |
| メラビアンの法則（7-38-55） | 極めて限定的な実験条件の結果。「見た目が9割」は原著者自身が否定 |
| 学習スタイル（視覚型・聴覚型） | 学習スタイルに合わせても成績は向上しないことが繰り返し示されている |
| 意志力は消耗する（自我消耗） | 大規模な多施設追試で効果が確認できなかった |
| モーツァルト効果 | 音楽で知能が上がるという主張は再現されていない |
| 社会的プライミング（老人語→歩行が遅くなる） | 追試に失敗。心理学の再現性危機の象徴的事例 |
| サブリミナル広告 | 元の実験は捏造だったと当人が告白している |
| 右脳人間・左脳人間 | 個人が片方の脳を優位に使うという証拠はない |
| 1万時間の法則 | 練習時間が説明する分散は分野により大きく異なる。時間だけでは決まらない |
| マシュマロ・テストで人生が決まる | 家庭の社会経済的地位を統制すると予測力は大幅に低下 |
| 笑顔を作ると楽しくなる（表情フィードバック） | 大規模追試で効果は非常に小さいか検出されず |
| ダニング・クルーガー効果 | グラフの形は統計的アーティファクトでも生じるという批判が強い |

注意が必要なため、**限定つきで**扱ったもの:

- **ミルグラムの服従実験** (`soc-007`): 手続きと解釈に批判があります。
  「人は権威に従う」と断定せず、事実として起きたことを書いています。
- **姿勢と呼吸** (`bod-015`): 姿勢が自信を変えるという主張は否定されている、
  と本文中で明示したうえで、呼吸への物理的影響のみ扱っています。
- **夜のスクリーン** (`bod-016`): 効果の大きさに議論があるため、
  「影響は条件による」と書き、断定を避けています。

## 追加するときの手順

1. `content/tips/` の該当カテゴリの JSON に追記する
2. `id` は既存と重複しない連番（例: `mem-026`）
3. `source` は必ず埋める（著者・年・掲載誌）
4. `python tests/validate.py --report` を通す
5. PR を出すと CI が自動で検証する

### 文字数について

**X の 280 制限が実質の上限**です。日本語は 1 文字が 2 とカウントされるため、
本文＋タグで日本語 140 文字が限界になります。既存の投稿は 180〜200 程度に
収めてあり、余裕があります。

`tests/validate.py --report` が上限に近い順に一覧を出すので、
追加後にそこを見れば危ないものがすぐ分かります。

### 表記の統一

- 断定を避ける表現: 「〜だった」「〜とされる」「〜傾向がある」
- 数値は原典に忠実に。丸める場合は「約」を付ける
- タグは `#心理学` を必ず入れ、もう 1 つカテゴリ別のタグを付ける
