# ADR-0004: 本体はタスク管理だけに絞る

- 日付: 2026-08-21
- 状態: 有効

## 背景

確定申告のデータ管理を扱いたい、という要望が出た。
今後も「請求書」「経費」「勤怠」と広がる見込みがある。

## 判断

**本体はタスク管理だけを持つ。** それ以外はすべて拡張として外に出す。

判断の基準を次のように決めた。

| 本体に入れてよいもの | 拡張に出すもの |
|---|---|
| タスク・プロジェクト・タグ・期限・優先度 | 特定の業務のためのデータ（帳簿、請求書、勤怠…） |
| 表示・検索・並べ替え・書き出しの土台 | 特定の業種・制度に依存する処理 |
| すべての利用者が使うもの | 一部の利用者だけが使うもの |

判断に迷ったら「これを使わない購入者がいるか」を問う。いるなら拡張にする。

## 理由

- 使わない機能のせいで画面が複雑になるのを防ぐ。導入の障壁を下げることが本製品の価値の中心にある
- 制度に依存する処理（税制など）は改正のたびに直す必要がある。本体と切り離しておけば、本体を触らずに更新できる
- 売り方として、本体を安く広く売り、必要な人にオプションを足してもらえる

## 帰結

- 拡張の仕組み（ホスト・パッケージ・署名・利用権）を先に作る必要が生じた
- 拡張点を増やすときは慎重に決める。一度公開した API は、外部の拡張が壊れるため削れない
- 本体のテストに「拡張が 0 個のとき、以前と同じ動きをするか」を含めた
