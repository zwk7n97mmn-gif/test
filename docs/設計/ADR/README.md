# ADR（設計判断の記録）

「なぜそうしたのか」を残す場所です。あとから読む人が、同じ議論を最初からやり直さずに済むように書きます。

- 一度書いた ADR は**書き換えません**。判断が変わったときは新しい ADR を足し、古いほうに「置き換え: ADR-000X」と 1 行だけ追記します。
- 1 ファイル 1 判断。短くて構いません。
