# データモデル

保存されるデータの形です。実装は `app/taskdeck.html` の 1 節と、各拡張の中にあります。

## 保存先

| キー | 中身 | 誰が書くか |
|---|---|---|
| `taskdeck.data.v1` | タスク・プロジェクト・設定 | 本体 |
| `taskdeck.license.v1` | ライセンスキーの文字列だけ | 本体 |
| `taskdeck.plugins.v1` | 読み込んだ拡張パッケージ（署名を含む） | 本体 |
| `taskdeck.ext.<拡張id>.v1` | その拡張のデータ | 拡張 |

すべて localStorage です。ブラウザとプロファイルが違えば別のデータになります。

## タスク（`taskdeck.data.v1`）

```jsonc
{
  "version": 1,
  "projects": [
    { "id": "l3x9", "name": "受注・請求", "color": "#2f6df6" }
  ],
  "tasks": [
    {
      "id": "l3xa",
      "title": "A社の見積書を送る",
      "notes": "先方の希望納期は月末",
      "projectId": "l3x9",
      "status": "todo",            // todo / doing / done
      "priority": 1,               // 1=高 2=中 3=低
      "due": "2026-08-31",         // YYYY-MM-DD または null
      "tags": ["経理"],
      "subtasks": [{ "id": "s1", "title": "金額を確認", "done": true }],
      "order": -3,                 // 小さいほど上。ドラッグで中間値を入れる
      "createdAt": "2026-08-20T05:00:00.000Z",
      "updatedAt": "2026-08-20T05:10:00.000Z",
      "completedAt": null
    }
  ],
  "settings": {
    "theme": "light",              // light / dark
    "view": "board",               // board / list
    "filter": { "type": "smart", "value": "all" },
    "sort": "order"
  }
}
```

### 決めごと

- **`order` は整数でなくてよい。** ドラッグで移動したとき、前後の値の中間（`(a+b)/2`）を入れます。並べ直しの計算をしないための割り切りです。
- **`completedAt` は `status` に従属する。** `done` にした瞬間に入り、戻すと `null` になります。
- **上限**: タイトル 500 文字、タグ 12 個（各 24 文字）、サブタスク 100 件。壊れたデータを読み込んだときの安全弁です。

### 読み込み時の修復（`normalize()`）

外から来た JSON は信用しません。読み込み時に必ず通します。

- 知らない `status` / `priority` は既定値に置き換える
- 存在しないプロジェクトを指すタスクは、先頭のプロジェクトに付け替える
- 日付として読めない `due` は `null` にする
- 配列でないもの、文字列でないものは捨てる

このため、古い版のバックアップや、手で編集した JSON を読ませても壊れません。

## ライセンス（`taskdeck.license.v1`）

```json
{ "key": "TD1.eyJ….MEUCIQ…" }
```

キーの文字列だけを保存します。中身（名義・プラン・権利）は、起動のたびに署名を検証して取り出します。
保存された内容を書き換えても、署名が合わなくなるだけです。
形式は [ライセンスキー仕様](../仕様/ライセンスキー仕様.md) を参照。

## 拡張（`taskdeck.plugins.v1`）

読み込んだパッケージをそのまま配列で持ちます。

```jsonc
[
  {
    "format": "taskdeck-package/1",
    "manifest": { "id": "tax", "name": "確定申告データ管理", "version": "1.0.0", "apiVersion": "1", … },
    "code": "api.registerView({ … })",
    "signature": "MEUCIQ…",
    "enabled": true
  }
]
```

**署名は起動のたびに検証します。** 保存されたあとで書き換えられていたら、
その拡張は自動的に停止し、一覧に理由が表示されます。

## 拡張のデータ（`taskdeck.ext.<id>.v1`）

形は拡張が決めます。本体は中身を知りません。
確定申告拡張の場合は次の形です。

```jsonc
{
  "version": 1,
  "settings": { "businessName": "山田デザイン事務所", "fiscalYear": 2026 },
  "accounts": [{ "code": "401", "name": "売上高", "type": "revenue" }],
  "entries": [
    {
      "id": "m1a",
      "date": "2026-04-05",
      "description": "A社 4月分 制作費",
      "memo": "",
      "taskId": "l3xa",          // 本体のタスクとの結び付き（任意）
      "lines": [
        { "code": "103", "debit": 330000, "credit": 0 },
        { "code": "401", "debit": 0,      "credit": 330000 }
      ],
      "createdAt": "2026-04-05T02:00:00.000Z"
    }
  ]
}
```

- 金額は**円単位の整数**です。小数は扱いません。
- 1 つの `lines` の中で、借方合計と貸方合計は必ず一致します（一致しないものは登録できません）。
- `type` は `asset` / `liability` / `equity` / `revenue` / `expense` の 5 つ。残高の向きは `asset` と `expense` が借方、それ以外が貸方です。

## バージョンの上げかた

キー名の末尾（`.v1`）を上げるのは、**古い形を読めなくする**ときだけです。
項目を足すだけなら `v1` のままにして、`normalize()` で既定値を補います。
利用者のデータは端末の中にしかないため、移行スクリプトを後から配れないからです。
