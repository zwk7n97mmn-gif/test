# はじめかた

TaskDeck を買った方が、最初に読む文書です。5 分あれば使いはじめられます。

## 1. 開く

配布された ZIP を展開し、**TaskDeck.html** をダブルクリックします。
いつものブラウザ（Chrome / Edge / Safari / Firefox）で開きます。

インストールも、アカウント登録も、インターネット接続も必要ありません。
よく使うなら、開いたページをブックマークしておくとすぐ戻れます。

## 2. ライセンスキーを登録する

1. 画面右上の **ライセンス** を押します。
2. 購入時のメールに書かれたキー（`TD1.` で始まる長い文字列）を貼り付けます。
3. **登録する** を押します。

登録すると、右上のバッジが「評価版」からプラン名に変わります。
登録するまでは評価版として動き、タスクは 30 件まで保存できます（機能の制限はありません）。

キーはこの端末のブラウザにだけ保存されます。認証のための通信は行いません。
端末を移したときは、同じキーをもう一度登録してください。

## 3. データがどこにあるかを知っておく

タスクは**お使いのブラウザの中**（localStorage）に保存されます。外部には送信されません。

そのため、次の場合はデータが消えます。

- ブラウザの「閲覧データの削除」でサイトデータを消したとき
- プライベートウィンドウで開いて閉じたとき
- 別のブラウザ・別の端末で開いたとき（データは共有されません）

右上の **⇅** から JSON ファイルとして書き出せます。**週に一度の書き出しをおすすめします。**
