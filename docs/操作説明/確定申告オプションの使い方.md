# 確定申告オプションの使い方

個人事業主の青色申告を想定した帳簿です。複式簿記で仕訳を記録すると、
総勘定元帳・試算表・損益計算書・貸借対照表まで自動で集計します。

> この拡張が行うのは**帳簿づけと集計**です。税額の計算や申告書の作成は行いません。
> 減価償却・家事按分・棚卸・消費税の処理は含まれません。
> 申告内容は最終的に税務署または税理士にご確認ください。

## 6 つの画面

| 画面 | 何をするところ |
|---|---|
| 仕訳の入力 | 日付・摘要・勘定科目・金額を入れて登録します |
| 仕訳帳 | その年度の仕訳を日付順に並べます |
| 総勘定元帳 | 勘定科目ごとの出入りと残高を追えます |
| 試算表 | 科目ごとの借方合計・貸方合計・残高。合計の一致を確かめます |
| 決算のまとめ | 収益・経費・所得と、損益計算書／貸借対照表の内訳 |
| 設定 | 屋号の登録、勘定科目の追加・削除 |

右上の「年度」で、集計する年を切り替えます（1月1日〜12月31日）。

## 仕訳を入れる

1. **日付**と**摘要**（例: 「A社 6月分 制作費」）を入れます
2. 行ごとに**勘定科目**を選び、**借方**または**貸方**に金額を入れます
3. 借方合計と貸方合計が一致すると登録できます

行が足りないときは「＋ 行を足す」。複数の科目にまたがる仕訳も入れられます。

**借方と貸方が合わないと登録できません。** 差額はその場に表示されるので、
どこがずれているかすぐ分かります。これが複式簿記の一番の利点です。

### よく使う形

| 場面 | 借方 | 貸方 |
|---|---|---|
| 売上を請求した（未入金） | 売掛金 | 売上高 |
| 請求した分が入金された | 普通預金 | 売掛金 |
| その場で現金売上 | 現金 | 売上高 |
| 経費を口座・カードで払った | （各経費科目） | 普通預金 |
| 経費を私費で立て替えた | （各経費科目） | 事業主借 |
| 事業のお金を私用に使った | 事業主貸 | 普通預金 |
| 外注費が未払い | 外注工賃 | 未払金 |

## タスクとつなぐ

タスクの詳細を開くと「この仕事の記帳」欄があります。

- **このタスクから仕訳を作る** … その仕事名で下書きができます（借方「売掛金」／貸方「売上高」）
- 記帳済みの仕訳は、その欄に一覧で出ます

「この案件、請求したっけ？」を、いつものタスク画面から確かめられます。

## 数字を確かめる

- **試算表**: 借方合計と貸方合計が一致していれば、記録に計算上の食い違いはありません
- **決算のまとめ**: 収益・経費・所得（収益 − 経費）と、科目ごとの内訳が出ます

青色申告決算書には、ここに出た金額を転記します。

## 書き出す

右上の **⇅** →「拡張の書き出し」から。

| ボタン | 中身 |
|---|---|
| 仕訳帳CSV | 1 行 1 明細。会計ソフトへの取り込みや、税理士への提出に |
| 試算表CSV | 科目ごとの集計と、収益・費用・所得の合計 |

どちらも Excel でそのまま開ける形式です（BOM 付き UTF-8）。

## 勘定科目を増やす

「設定」から、コード・科目名・区分（資産／負債／資本／収益／費用）を指定して追加します。
すでに仕訳で使っている科目は削除できません。

## データの保管

仕訳はブラウザの中（この拡張専用の保存領域）にあります。
**本体の JSON バックアップには含まれません。**
確定申告の記録は大切なので、月に一度は仕訳帳CSVを書き出して保管してください。
