# TaskDeck 使い方マニュアル

バージョン 1.0 ／ 対応ブラウザ: Chrome・Edge・Safari・Firefox の最新版

---

## 1. 起動する

`TaskDeck.html` をダブルクリックするだけです。インストールも、アカウント作成も、
インターネット接続も要りません。

よく使う場合は、開いたページをブックマークしておくとすぐ戻れます。

> **大切なこと**
> タスクは「開いているブラウザ」の中に保存されます。
> 別のブラウザや別の端末で開くと、中身は空から始まります。
> 移すときは 6 章のバックアップをお使いください。

---

## 2. 画面の見かた

| 場所 | 役割 |
|---|---|
| 左側 | ビュー（今日・今週・重要・すべて・完了済み）、プロジェクト、タグ |
| 中央上 | タスクの入力欄 |
| 中央 | ボード表示（未着手・進行中・完了の 3 列）またはリスト表示 |
| 右上 | テーマ切り替え、キーボード操作の説明、データの保存と読み込み、ライセンス |

「今日」には、期限が今日までのタスクが集まります。まずここだけ見れば、
その日にやることが分かります。

---

## 3. タスクを追加する

中央の入力欄に打ち込んで **Enter** を押します。
このとき、次の書き方を混ぜると、まとめて設定できます。

| 書き方 | 意味 | 例 |
|---|---|---|
| `#ことば` | タグを付ける | `#経理` `#至急` |
| `!1` `!2` `!3` | 優先度（高・中・低） | `!1` |
| `@今日` `@明日` `@明後日` `@来週` | 期限 | `@明日` |
| `@月曜`〜`@日曜` | 次のその曜日 | `@金曜` |
| `@8-31` `@2026-08-31` | 日付で指定 | `@9-15` |

例）

```
請求書を送る #経理 !1 @明日
```

→ タイトル「請求書を送る」、タグ「経理」、優先度「高」、期限「明日」のタスクになります。

プロジェクトを選んでいるときに追加すると、そのプロジェクトに入ります。

---

## 4. タスクを進める

- **完了にする** … カード右上の丸印を押します。もう一度押すと未着手に戻ります。
- **列を移す** … カードをドラッグして「進行中」「完了」へ落とします。並び順も変わります。
- **中身を開く** … カード（リストなら行）を押すと、右側に詳細が開きます。

詳細では、タイトル・状態・優先度・期限・プロジェクト・タグ・サブタスク・メモを直せます。
直した内容はその場で保存されます。「保存」ボタンはありません。

### サブタスク

「＋ サブタスクを追加」で細かい手順を並べられます。
チェックした数はカードに `2/5` のように出るので、進み具合がひと目で分かります。

---

## 5. 探す・絞り込む

- **検索** … 右上の検索欄に入れると、タイトル・メモ・タグ・サブタスクをまとめて探します。
  空白で区切ると、すべてを含むものだけが残ります（例: `請求 経理`）。
- **プロジェクト** … 左のプロジェクト名を押すと、そのプロジェクトだけになります。
- **タグ** … 左のタグを押すと、そのタグが付いたものだけになります。
- **並べ替え** … リスト表示で見出し（状態・優先度・期限など）を押すと並び替わります。
  もう一度押すと元の並びに戻ります。

---

## 6. データを持ち出す・戻す（バックアップ）

右上の **⇅** を押します。

| ボタン | 使いどころ |
|---|---|
| JSON で書き出す | まるごとバックアップする。別の端末へ移すときもこれ |
| CSV で書き出す | Excel や Googleスプレッドシートで集計・報告に使う |
| JSON を読み込む | 書き出したファイルから元に戻す（いまの内容は置き換わります） |
| 印刷する | いま表示している一覧をそのまま紙・PDF にする |

**別の端末へ移す手順**
1. いまの端末で「JSON で書き出す」。
2. できたファイルを新しい端末へ渡す。
3. 新しい端末で `TaskDeck.html` を開き、「JSON を読み込む」。
4. ライセンスキーをもう一度登録する。

週に一度の書き出しをおすすめします。ブラウザの掃除機能でデータが消えても、これがあれば戻せます。

---

## 7. キーボードだけで操作する

| キー | はたらき |
|---|---|
| `N` | 入力欄へ移動 |
| `/` | 検索欄へ移動 |
| `↑` `↓` | タスクを選ぶ |
| `E` または `Enter` | 選んだタスクを開く |
| `Space` | 完了を切り替える |
| `1` `2` `3` | 未着手 / 進行中 / 完了 にする |
| `Delete` | 削除する（画面下の「元に戻す」で取り消せます） |
| `Esc` | パネルやダイアログを閉じる |

---

## 8. ライセンスキー

購入前は評価版として動き、タスクは 30 件まで保存できます（機能の制限はありません）。

1. 右上の「ライセンス」を押す。
2. メールで届いたキー（`TD1.` で始まる文字列）を貼り付ける。
3. 「登録する」を押す。

登録するとバッジがプラン名に変わり、件数の上限がなくなります。
キーは端末の中だけで確認され、外部への通信は発生しません。
台数はご購入のプランの範囲でお使いください。

---

## 9. 困ったとき

**Q. タスクが消えた**
ブラウザの閲覧データを削除すると消えます。書き出した JSON があれば戻せます。
プライベートウィンドウで使っていた場合、閉じると消えます。

**Q. 別のパソコンでも同じタスクを見たい**
6 章の手順で JSON を移してください。自動で同期する仕組みは入っていません
（そのぶん、外部にデータを預けずに済みます）。

**Q. キーが「正しくありません」と出る**
前後の余分な文字や改行が入っていないか確かめて、もう一度すべて貼り直してください。
それでも直らない場合は、ご購入時のメールを添えてサポートへご連絡ください。

**Q. 会社のパソコンで使える？**
ファイルを開くだけなので、多くの環境でそのまま動きます。
外部との通信がないため、持ち出し制限のある環境でも使いやすい作りです。
