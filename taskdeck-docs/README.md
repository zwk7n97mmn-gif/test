# TaskDeck ドキュメント

TaskDeck（単一 HTML ファイルで動くタスク管理ツール）と、その拡張パッケージについての
操作説明・設計・仕様をまとめた場所です。すべて Markdown で書いてあります。

製品のソースコードは別リポジトリ（`taskdeck/`）にあります。ここには文章だけを置きます。

## どこから読むか

| 読む人 | 入口 |
|---|---|
| 買った人・使う人 | [操作説明](docs/操作説明/はじめかた.md) |
| 拡張を作る人 | [拡張の作り方](docs/開発/拡張の作り方.md) → [拡張API仕様](docs/仕様/拡張API仕様.md) |
| 中身を引き継ぐ人 | [全体アーキテクチャ](docs/設計/全体アーキテクチャ.md) → [ADR](docs/設計/ADR/) |
| 売る人・運用する人 | [リリース手順](docs/開発/リリース手順.md) |

## この文書群の約束

1. **仕様は実装に合わせる。** 実装を変えたら、同じ変更のなかで仕様も直します。
2. **迷ったら実物を見る。** 食い違いを見つけたら、実装を正として仕様を直し、[CONTRIBUTING.md](CONTRIBUTING.md) の手順で記録します。
3. **決めた理由を残す。** 「なぜこうしたか」は ADR に書きます。あとから読む人のためのものです。

対象バージョン: TaskDeck 1.0.0 / 拡張API v1
