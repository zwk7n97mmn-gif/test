# データ保存形式仕様

保存場所と、書き出し・読み込みの形式です。

## localStorage のキー

| キー | 中身 | 消えるとき |
|---|---|---|
| `taskdeck.data.v1` | タスク・プロジェクト・設定 | ブラウザのサイトデータ削除、「すべてのデータを消す」 |
| `taskdeck.license.v1` | ライセンスキーの文字列 | 同上、「登録を解除」 |
| `taskdeck.plugins.v1` | 読み込んだ拡張パッケージ | 同上、拡張の取り外し |
| `taskdeck.ext.<id>.v1` | 拡張ごとのデータ | 同上、その拡張の取り外し |

中身の形は [データモデル](../設計/データモデル.md) を参照してください。

## 保存の動き

- 変更のたびに `save()`。実際の書き込みは 120 ミリ秒ぶんまとめる
- `pagehide` / `beforeunload` / `visibilitychange`（隠れたとき）に書き残しを流す
- 書き込みに失敗したら（容量超過など）画面下にメッセージを出す。**黙って失敗しない**
- 別タブでの変更は `storage` イベントで取り込む

## JSON 書き出し（バックアップ）

ファイル名: `taskdeck-backup-YYYYMMDD.json`

`taskdeck.data.v1` の中身をそのまま、読みやすく整形して書き出します。

**含まれないもの**: ライセンスキー、拡張パッケージ、拡張のデータ。
別の端末へ移すときは、キーの再登録と拡張の再読み込みが必要です。

## JSON 読み込み

- 読み込むと、いまのデータは**置き換わります**（追加ではありません）。確認のダイアログが出ます
- 読み込んだ内容は `normalize()` を通ります。項目が欠けていても、余計な項目があっても壊れません
- テーマ設定も読み込んだ内容に従います

## CSV 書き出し（本体）

ファイル名: `taskdeck-tasks-YYYYMMDD.csv`
文字コード: UTF-8（BOM 付き。Excel でそのまま開けます）／改行 CRLF ／全項目を `"` で囲む

| 列 | 内容 |
|---|---|
| タイトル / 状態 / 優先度 / 期限 / プロジェクト / タグ | 表示と同じ値。タグは空白区切り |
| サブタスク完了 / サブタスク合計 | 数値 |
| メモ | 改行は ` / ` に置き換え |
| 作成日時 / 更新日時 | `2026/8/21 14:05` 形式 |

## CSV 書き出し（確定申告拡張）

**仕訳帳CSV** `shiwake-<年度>.csv`

| 列 |
|---|
| 日付 / 摘要 / 勘定科目 / 借方金額 / 貸方金額 / メモ / 関連タスク |

1 行が仕訳の 1 明細です。1 つの仕訳が複数行になります。

**試算表CSV** `shisanhyo-<年度>.csv`

| 列 |
|---|
| コード / 勘定科目 / 区分 / 借方合計 / 貸方合計 / 残高 |

末尾に、収益合計・費用合計・所得（利益）の 3 行が付きます。

## 容量について

localStorage の上限は、ブラウザにもよりますがおおむね 5 MB です。目安として、

- タスク 1 件 … 200〜400 バイト（メモの長さ次第）
- 仕訳 1 件 … 200 バイト前後
- 拡張パッケージ … 30〜40 KB

数万件を入れても上限には届きません。届いた場合は書き込みが失敗し、画面にメッセージが出ます。

## バージョンの上げかた

キー末尾の `.v1` を上げるのは、**古い形を読めなくする**ときだけです。
項目を足すだけなら `v1` のままにし、`normalize()` で既定値を補います。
利用者のデータは端末の中にしかなく、あとから移行処理を配れないためです。
