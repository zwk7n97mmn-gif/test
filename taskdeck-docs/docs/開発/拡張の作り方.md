# 拡張の作り方

30 分で、動く拡張を 1 つ作れます。
必要なのは Python 3.11 以上と、テキストエディタだけです。

前提として [拡張API仕様](../仕様/拡張API仕様.md) を横に置いて読んでください。

## 1. フォルダを用意する

```
taskdeck/extensions/<あなたの拡張id>/
├── manifest.json
├── main.js
└── README.md      （購入者向けの説明。配布 ZIP に同梱されます）
```

`extensions/sample-counter/` に、動く最小の見本があります。まずはこれを写して始めるのが早道です。

## 2. manifest.json を書く

```json
{
  "id": "invoice",
  "name": "請求書作成",
  "version": "1.0.0",
  "apiVersion": "1",
  "vendor": "〔販売者名〕",
  "description": "タスクから請求書を起こし、PDF 用の印刷画面まで出します。",
  "entitlement": "invoice",
  "trialLimit": 5
}
```

- `id` は小文字英数字とハイフンだけ。あとから変えられません（保存領域の名前になります）
- `trialLimit` は、ライセンスの権利が無いときに拡張へ伝わる上限です。使い方は拡張が決めます

## 3. main.js を書く

```js
// api はこのコードに渡されます。トップレベルでそのまま使えます。
const state = api.storage.get({ items: [] });

api.ui.injectStyle(`.inv-box{padding:12px}`);   // 本体の CSS 変数を使えます

api.registerView({
  id: "main",
  label: "請求書",
  icon: "▤",
  render(box) {
    box.innerHTML = `<div class="plugin-host inv-box">
      <p>${state.items.length} 件</p>
      <button class="btn primary" id="add">追加する</button>
    </div>`;
    box.querySelector("#add").onclick = () => {
      if (!api.entitled && state.items.length >= api.trialLimit) {
        api.ui.toast(`評価中は ${api.trialLimit} 件までです`);
        return;
      }
      state.items.push({ id: Date.now(), title: "新しい請求書" });
      api.storage.set(state);
      api.ui.refresh();
    };
  },
});
```

### 守ること

| 決まり | 理由 |
|---|---|
| 起動のたびに実行されても同じ結果になるように書く | 拡張の入れ替えやライセンス変更のたびに読み直されます |
| 入力途中の値は変数に持つ | 本体の描き直しで DOM は消えます |
| 利用者の入力を表示するときは `api.ui.escapeHtml()` を通す | 表示の崩れと、危険な埋め込みを防ぎます |
| `localStorage` を直接触らない | 取り外したときに残骸が残ります |
| 本体の DOM を触らない | 次の描き直しで消えるか、本体を壊します |

### 描き直しの落とし穴

入力のたびに画面全体を作り直すと、**ボタンを押した瞬間にボタンが消えて、クリックが取りこぼされます**。
値が変わるたびに更新したい場所（合計欄など）は、そこだけを書き換えてください。

```js
input.oninput = () => { draft.amount = input.value; totals.innerHTML = totalsHtml(draft); };
```

## 4. 署名して読み込む

```bash
python3 taskdeck/tools/keygen.py init          # まだ鍵が無い場合だけ
python3 taskdeck/tools/pkg.py build taskdeck/extensions/invoice
# → taskdeck/dist/invoice-1.0.0.tdpkg
```

アプリを開き、右上の **⊞** →「パッケージのファイルを選ぶ」で読み込みます。
直すたびに `build` して読み込み直せば、上書き更新されます（保存データは残ります）。

開発中は「文字列を貼り付けて追加」のほうが速いこともあります。

## 5. 動きを確かめる

手で確かめるだけでなく、テストを 1 本書いておくと後で楽です。
`tests/ui_extension.mjs` が、使い捨ての鍵で
「アプリの組み立て → 署名 → 読み込み → 操作 → 取り外し」までを通しています。
これを写して、自分の拡張向けに書き換えるのが早道です。

```bash
npm i playwright
node taskdeck/tests/ui_extension.mjs
```

## 6. 売る

```bash
bash taskdeck/tools/build.sh     # dist/taskdeck-<id>-<version>.zip ができます
python3 taskdeck/tools/keygen.py issue --name "購入者名" --ext invoice
```

購入者は、パッケージを読み込み、届いたキーに貼り替えるだけです。

## よくある詰まり

| 症状 | 原因 |
|---|---|
| 「署名が確認できませんでした」 | `build` し直していない。パッケージを手で編集した |
| 一覧に赤い文字が出て自動で止まる | `code` の実行時に例外。文言に原因が出ています |
| 保存したはずのデータが消える | `api.storage.set()` を呼び忘れている。または `localStorage` を直接触っている |
| 画面が真っ白 | `render` の中で例外。その場に赤い枠で理由が出ます |
| 初回は動くのに、再読み込みで止まる | 保存データを読む経路だけ通る初期化の順序ミス。`const` の宣言より前で使っていないか確認 |
