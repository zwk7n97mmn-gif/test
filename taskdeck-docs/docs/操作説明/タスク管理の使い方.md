# タスク管理の使い方

## 画面の見かた

| 場所 | 役割 |
|---|---|
| 左 | ビュー（今日・今週・重要・すべて・完了済み）、プロジェクト、拡張、タグ |
| 中央上 | タスクの入力欄 |
| 中央 | ボード表示（未着手・進行中・完了）またはリスト表示 |
| 右上 | テーマ、キーボード操作、拡張、データの保存と読み込み、ライセンス |

「今日」には、期限が今日までのタスクが集まります。朝はここだけ見れば足ります。

## タスクを足す

入力欄に打ち込んで **Enter**。次の書き方を混ぜると、まとめて設定できます。

| 書き方 | 意味 | 例 |
|---|---|---|
| `#ことば` | タグを付ける | `#経理` |
| `!1` `!2` `!3` | 優先度（高・中・低） | `!1` |
| `@今日` `@明日` `@明後日` `@来週` | 期限 | `@明日` |
| `@月曜`〜`@日曜` | 次のその曜日 | `@金曜` |
| `@8-31` `@2026-08-31` | 日付で指定 | `@9-15` |

```
請求書を送る #経理 !1 @明日
```

→ タイトル「請求書を送る」、タグ「経理」、優先度「高」、期限「明日」になります。

プロジェクトを選んでいるときに追加すると、そのプロジェクトに入ります。

## 進める

- **完了にする**: カード右上の丸印を押す（もう一度で戻る）
- **列を移す**: カードをドラッグして落とす。落とした位置で並び順も決まる
- **中身を開く**: カード（リストなら行）を押すと右側に詳細が開く

詳細で直した内容はその場で保存されます。保存ボタンはありません。

### サブタスク

「＋ サブタスクを追加」で手順を並べられます。チェックした数はカードに `2/5` のように出ます。

## 探す

- **検索**（右上）: タイトル・メモ・タグ・サブタスクをまとめて探します。空白で区切るとすべてを含むものだけが残ります
- **プロジェクト / タグ**: 左のメニューから絞り込みます
- **並べ替え**: リスト表示で見出しを押すと並び替わります。もう一度押すと元の並びに戻ります

## 持ち出す・戻す

右上の **⇅** から行います。

| ボタン | 使いどころ |
|---|---|
| JSON で書き出す | まるごとバックアップ。別の端末へ移すときもこれ |
| CSV で書き出す | Excel で集計・報告に使う |
| JSON を読み込む | 書き出したファイルから戻す（いまの内容は置き換わります） |
| 印刷する | 表示中の一覧をそのまま紙・PDF にする |

> 拡張（オプション）が保存したデータは、この JSON には**含まれません**。
> 拡張ごとの書き出し（CSV）を別に取ってください。

## キーボード操作

| キー | はたらき |
|---|---|
| `N` | 入力欄へ |
| `/` | 検索欄へ |
| `↑` `↓` | タスクを選ぶ |
| `E` / `Enter` | 開く |
| `Space` | 完了を切り替える |
| `1` `2` `3` | 未着手 / 進行中 / 完了 |
| `Delete` | 削除（画面下の「元に戻す」で取り消せます） |
| `Esc` | 閉じる |
