# 拡張（オプション）の入れかた

TaskDeck の本体はタスク管理だけを持っています。
それ以外の機能は「拡張パッケージ」として別に配布され、必要な人だけが足せます。

## 入れる

1. TaskDeck.html を開く
2. 右上の **⊞** を押す
3. **パッケージのファイルを選ぶ** を押して、購入時に届いた `.tdpkg` ファイルを選ぶ
4. 追加されると、左のメニューに項目が増えます

ファイルを選べない環境では、**文字列を貼り付けて追加** から、
パッケージの中身をそのまま貼り付けることもできます。

## 使えるようにする（ライセンス）

拡張には、それぞれ利用する権利が必要です。
オプションを購入すると、その権利が入った**新しいライセンスキー**が届きます。

1. 右上の **ライセンス** を押す
2. 届いた新しいキーに貼り替える
3. **登録する** を押す

拡張の一覧（⊞）で、その拡張が「製品版」と表示されれば完了です。

権利がなくても拡張は動きますが、扱えるデータの件数に上限があります
（確定申告オプションなら仕訳 30 件まで）。買う前に試せます。

## 止める・外す

拡張の一覧（⊞）で操作します。

- **使う のチェックを外す** … 一時的に止めます。データは残ります
- **取り外す** … 拡張と、その拡張が保存したデータをまとめて消します

> **取り外す前に書き出してください。** 拡張のデータは本体の JSON バックアップに含まれません。
> 取り外すと元に戻せません。

拡張を外したあとの本体は、拡張を入れる前とまったく同じ動きに戻ります。

## 安全のしくみ

拡張パッケージには販売元の電子署名が入っています。
アプリは読み込むたびに署名を確かめ、**署名のないもの・途中で書き換えられたものは動かしません**。

拡張ができることは、アプリが用意した窓口の範囲に限られています
（独自画面の表示、タスクの読み書き、拡張自身の保存領域、書き出しの追加）。
拡張から外部へ通信する仕組みは用意していません。

## うまくいかないとき

| 症状 | 確認すること |
|---|---|
| 「署名が確認できませんでした」 | 販売元から届いたファイルをそのまま使っているか。編集していないか |
| 「拡張 API v… 向けです」 | 本体が古い可能性があります。更新版をお使いください |
| 一覧に赤い文字が出る | 拡張の読み込み中にエラーが起きています。販売元へその文言をお知らせください |
| 「使う」のチェックが勝手に外れる | 上と同じ。安全のため自動で止まります |
