# ADR-0005: 確定申告拡張は複式簿記で作る

- 日付: 2026-08-21
- 状態: 有効

## 背景

最初のオプションとして、確定申告向けのデータ管理を作る。
帳簿の方式には、単式簿記（簡易帳簿）と複式簿記がある。

## 判断

**複式簿記**で作る。仕訳を借方・貸方で記録し、総勘定元帳・試算表・
損益計算書・貸借対照表まで集計する。

## 理由

- 青色申告の 65 万円控除には複式簿記による記帳が要る。ここが購入の動機になる
- 借方と貸方が一致しないと登録できないため、入力ミスがその場で分かる。単式では気づけない
- 試算表・決算の集計まで機械的に導ける。単式だと集計の意味が弱く、表計算ソフトとの差が出ない

## 引き換えに失うもの

- 入力の難しさが上がる。簿記を知らない人には敷居が高い
  - → よく使う仕訳の形を表にして、マニュアルと画面の下に置く
  - → タスクから「売掛金／売上高」の下書きを作れるようにして、いちばん多い場面を簡単にする
- 実装量が増える（拡張だけで 650 行ほど）

## 範囲の線引き

この拡張が**やること**: 仕訳の記録、元帳・試算表・決算の集計、CSV 書き出し。

**やらないこと**: 税額の計算、申告書の作成・提出、減価償却の計算、家事按分、棚卸、消費税の処理。

これらは制度の改正が頻繁で、誤ると利用者の不利益が大きい。
「帳簿づけの道具」として範囲を明示し、画面・マニュアル・販売ページの 3 か所に同じ注意を書く。
