# ADR-0001: 単一 HTML ファイルで配布する

- 日付: 2026-08-20
- 状態: 有効

## 背景

買い切りで売るタスク管理ツールを作る。配布・導入・サポートの手間を最小にしたい。
想定する購入者には、ソフトのインストール権限がない端末を使う人が含まれる。

## 判断

製品を **1 つの HTML ファイル**にする。CSS も JavaScript も内側に書き、外部への読み込みを一切持たない。
ビルド工程（バンドラ、トランスパイラ、パッケージマネージャ）を導入しない。

## 理由

- ダブルクリックで開ける。インストール作業も権限も要らない
- 通信が無いことを、購入者自身が開発者ツールで確認できる。「外に出さない」が売り文句として成立する
- 依存パッケージがないので、5 年後も同じファイルが同じように動く
- 販売者の手元でも、Node のバージョン差などに悩まされない

## 引き換えに失うもの

- 型検査やモジュール分割の恩恵がない。1 ファイルが長くなる（現状 1,900 行ほど）
  - → ソース内を番号つきの節に分け、節番号をこの文書群と対応させることで補う
- 差分描画の仕組みがなく、状態が変わるたびに全部描き直す
  - → 数千件までは実測で問題なし。問題が出たら再検討する
- 製品を書き換えられると制限を外せる
  - → [ADR-0002](0002-ライセンスを公開鍵方式にする.md) で扱う範囲を定めた
