# 用語集

📍`🏠ホーム > 🔰はじめに > 用語集`

---

このwikiで繰り返し出てくる言葉の意味です。**社内でしか通じない言い方**も含めて並べます。

<br>

---

## 📖 wikiまわり

| 言葉 | 意味 |
| --- | --- |
| **パンくず** | ページ先頭の `📍` の行。ホームからそのページまでの経路。 |
| **アンカー** | 目次からのジャンプ先。`<a id="xxx"></a>` を見出し行の内側に置く。 |
| **孤立ページ** | READMEからもどのページからも辿れないページ。検査で落ちる。 |
| **検査（lint）** | `scripts/wiki_lint.py`。決まりごとを守れているかを機械で確かめる。 |
| **キット** | `wiki-kit`。このwikiの雛形と検査の配布元。 |

<br>

## 📖 製品まわり

| 言葉 | 意味 |
| --- | --- |
| **TaskDeck** | 単体HTMLで動くタスク管理ツール。→ [TaskDeck](../製品/TaskDeck.md) |
| **拡張パッケージ** | TaskDeck に後から足せるオプション。`.tdpkg` という署名付きの箱で配る。 |
| **エンタイトルメント** | ライセンスに書かれた「使ってよい拡張の一覧」。 |
| **体験版制限** | ライセンスが無いときの上限（件数など）。拡張ごとに決める。 |

<br>

## 📖 仕組みまわり

| 言葉 | 意味 |
| --- | --- |
| **Gitea Actions** | Gitea に組み込まれた自動実行。GitHub Actions とほぼ同じ書き方。 |
| **ラベル起動** | Issue にラベルが付いた時だけ自動実行を動かすやり方。 |
| **サブスクリプション認証** | 契約プランの枠でAIを動かす認証。上限に達すると**失敗するだけ**で追加課金されない。 |
| **ツリー照合** | 説明に書いた構成図と実際のファイルを突き合わせる検査。→ [ツリーと実体の突き合わせ](../開発ルール/ツリーと実体の突き合わせ.md) |
