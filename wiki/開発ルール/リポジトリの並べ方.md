## <a id="problem"></a>1. 困ること

リポジトリが20を超えると、次のことが起きます。

| 困ること | 起きる理由 |
| --- | --- |
| どれが本番か分からない | 名前が似ている物が並ぶ |
| 使われていない物が残る | 消してよいか誰も判断できない |
| 新しい人が入口を見つけられない | 一覧がどこにも無い |

<br>

---

## <a id="hub"></a>2. 入口を1枚作る

**全体像を書いた1枚**を用意し、そこから各リポジトリへ飛ばします。

| 書くこと | 例 |
| --- | --- |
| 何をするものか | 一言で |
| どのまとまりに属するか | 業務システム／道具／ドキュメント |
| 生きているか | 使用中／保守のみ／⛔廃止 |

> ⚠️ **⛔廃止したものも消さずに残してください。**<br>
> 「これは何だったのか」を調べる人が必ず現れます。廃止と書いてあること自体が答えになります。

<br>

## <a id="name"></a>3. 名前と実体を分ける

**呼び名**と**実際のリポジトリ名**は一致しないことがあります。

| 呼び名 | 実際のリポジトリ |
| --- | --- |
| 〇〇のソース | `〇〇` |
| 〇〇の道具 | `〇〇_tools` |

一覧では**両方**を持たせます。呼び名だけだとリンクが張れず、
リポジトリ名だけだと**会話で使う言葉と繋がらない**ためです。

<br>

---

## <a id="check"></a>4. 機械で確かめる

一覧は、放っておくと**必ず実物とずれます**。次の2つを検査で見ます。

| 検査 | 見つかるもの |
| --- | --- |
| 一覧と実物の突き合わせ | 一覧に無いリポジトリ／消えたリポジトリ |
| リンク切れ | 移動・改名で切れたリンク |

> 💡 リンクは**参照形式**で書くと、URL の変更が1か所で済みます。
> サーバを引っ越したときに全ページを直す羽目になりません。
