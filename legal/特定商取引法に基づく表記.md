# 特定商取引法に基づく表記

> **販売者の方へ**
> このページは、日本国内で有料のソフトウェアを販売する場合に掲示が必要な項目の雛形です。
> 〔　〕の部分をご自身の情報に置き換えて、販売ページから必ずたどれる場所に掲載してください。
> 個人事業主の場合、住所・電話番号は「請求があったら遅滞なく開示する」旨の記載で代えられる場合があります（消費者庁の運用に従ってください）。
> 記載内容の最終的な確認は、必要に応じて専門家にご相談ください。

| 項目 | 内容 |
|---|---|
| 販売事業者 | 〔氏名または法人名〕 |
| 運営統括責任者 | 〔氏名〕 |
| 所在地 | 〔郵便番号・住所〕 |
| 電話番号 | 〔電話番号〕（受付時間: 〔平日 10:00〜17:00〕） |
| メールアドレス | 〔メールアドレス〕 |
| ホームページ | 〔URL〕 |
| 販売価格 | 各商品ページに表示された金額（消費税込み） |
| 商品代金以外の必要料金 | インターネット接続料金等はお客様のご負担となります |
| 支払方法 | クレジットカード（〔決済サービス名〕による決済） |
| 支払時期 | ご注文時にお支払いが確定します |
| 引渡し時期 | 決済完了後ただちに、ダウンロードURLとライセンスキーをメールでお送りします |
| 動作環境 | Chrome・Edge・Safari・Firefox の最新版が動作するパソコン |
| 返品・キャンセル | デジタル商品の性質上、購入後の返品はお受けできません。ただし、動作しない場合は購入後14日以内にご連絡ください。修正版の提供または返金にて対応します |
| 返金方法 | 〔決済サービス名〕を通じて、ご購入時の決済手段へ返金します |
