## <a id="what"></a>1. 何が置いてあるか

**自分たちで作った道具の説明書**です。

| 置いてあるもの | 例 |
| --- | --- |
| 何ができるのか | [TaskDeck](../製品/TaskDeck.md) の機能一覧 |
| どう使うのか | [ページを追加する](../作業フロー/ページを追加する.md) |
| なぜそうしたのか | 決まりごとの理由（各ページの「⚠️」の後ろ） |

置かないものもあります。

| 置かないもの | どこにあるか |
| --- | --- |
| ソースコード | 各リポジトリ |
| 動く物そのもの | 各リポジトリ |
| 個人のメモ | 各自の手元 |

> ℹ️ ソースと説明が同じ場所にあると、**どちらが正しいか分からなくなります**。
> ここは説明だけを置く場所です。

## <a id="layout"></a>3. ページの並べ方

**フォルダは README の見出しに対応します。**

| フォルダ | READMEの見出し | 入れるもの |
| --- | --- | --- |
| `はじめに/` | 🔰はじめに | 最初に読むもの |
| `作業フロー/` | 👷作業フロー | 手順 |
| `開発ルール/` | 👷開発ルール | 守ってほしい決まり |
| `製品/` | 📄製品・仕組み | 作った物の説明書 |
| `wikiの編集方法/` | ✏️wikiの編集方法 | このwiki自身の決まり |

> ⚠️ **フォルダを新しく作るときは、README の見出しも一緒に作ってください。**<br>
> README から辿れないページは検査（`orphans`）で落ちます。

<br>

## <a id="writing"></a>4. 書く側になったら

1. [ページの書き方](../wikiの編集方法/ページの書き方.md) を読む
2. `wikiの編集方法/テンプレート/` から用途に合うものをコピーする
3. [ページを追加する](../作業フロー/ページを追加する.md) の手順どおりに進める
