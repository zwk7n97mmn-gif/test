## <a id="overview"></a>1. 何ができるか

| できること | 説明 |
| --- | --- |
| タスクの登録・編集 | 期限・優先度・タグ・メモ |
| ボード表示 | 未着手／進行中／完了 の3列 |
| スマートビュー | 今日・今週・期限切れ・タグ別で絞り込む |
| 検索 | 題名・メモ・タグを横断 |
| 書き出し／読み込み | JSON ファイル |
| 印刷 | 一覧をそのまま紙に |

## <a id="policy"></a>2. 作りの方針

| 方針 | 理由 |
| --- | --- |
| **HTMLファイル1つ** | 買った人が**ダブルクリックで使える**。サーバも設定も要らない |
| **依存ライブラリなし** | 配布物が壊れない。CDN が消えても動く |
| **通信しない** | 業務データを外に出さない。社内規程の審査を通しやすい |
| **`file://` で動く** | 添付ファイルとして配れる |

> 🚨 **この4つは製品の売りそのものです。**<br>
> 便利さのために外部ライブラリを足すと、**買う理由が消えます**。

## <a id="data"></a>3. データの持ち方

ブラウザの `localStorage` に保存します。

| 場面 | 動き |
| --- | --- |
| 入力中 | 少し待ってからまとめて保存する（打つたびに書かない） |
| タブを閉じる／隠れる | **その場で保存し切る** |

> ⚠️ **待っている間にタブを閉じられると、入力が消えます。**<br>
> 閉じる直前・隠れる直前に保存し切る処理を必ず残してください。
> 実際にこれで1回データが飛んでいます。

バックアップは JSON の書き出しで取ります。ブラウザのデータを消すと**保存内容も消える**ため、
定期的な書き出しを利用者に案内しています。

## <a id="license"></a>4. ライセンス

ライセンスキーは**通信せずに本物かどうかを確かめられる**形にしてあります。

| 項目 | 中身 |
| --- | --- |
| 方式 | 楕円曲線（P-256）の電子署名 |
| 秘密鍵 | 売る側だけが持つ。発行に使う |
| 公開鍵 | アプリに埋め込む。検証に使う |
| 中身 | 宛名・発行日・使ってよい拡張の一覧 |

- 発行: `tools/keygen.py`
- 検証: アプリ内で行う（外部ライブラリなし）

> ⚠️ **秘密鍵を配布物に入れないでください。** 入れた時点で誰でも発行できます。
