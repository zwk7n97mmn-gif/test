# BOOTH の商品説明欄に貼る文面

BOOTH の商品説明欄は**書式がほとんど使えません**（太字・表・見出しが効かない）。
そのため、記号と改行だけで読めるように作ってあります。

> ⚠️ **〔　〕は必ず置き換えてください。** 置き換え漏れは
> `python3 tools/preflight.py` が見つけます。

---

## 商品の分け方

BOOTH では**プランごとに商品を分けて**出品します。
バリエーションではなく別商品にするのは、プランごとに説明と価格が違うためです。

| 商品名 | 価格の目安 |
| --- | --- |
| TaskDeck パーソナル（1台） | 3,000〜4,000円 |
| TaskDeck ビジネス（5台） | 12,000〜15,000円 |
| TaskDeck サイトライセンス | 40,000〜60,000円 |
| TaskDeck 確定申告オプション | 6,000〜8,000円 |

---

## 共通部分（どの商品にも入れる）

以下をコピーして、冒頭の「■ このプランについて」だけプランごとに差し替えてください。

```
━━━━━━━━━━━━━━━━━━━━
TaskDeck - 通信しないタスク管理ツール
━━━━━━━━━━━━━━━━━━━━

HTMLファイル1つで動くタスク管理ツールです。
インストール不要・アカウント登録不要・サーバー不要。
ダブルクリックするだけで使えます。

■ このプランについて
〔プランごとの説明をここに。下の「プラン別の冒頭」から選んで貼る〕

■ ⚠ ライセンスキーのお届けについて（必ずお読みください）
ご購入後、BOOTHのメッセージにて
ライセンスキーを〔1営業日〕以内にお送りします。

キーが届く前でも、ダウンロードしたファイルはそのままお使いいただけます。
（タスク管理の機能はすべて使えます。オプションのみ体験版の制限がかかります）

■ できること
・タスクの登録、編集（期限・優先度・タグ・メモ）
・ボード表示（未着手／進行中／完了）
・今日／今週／期限切れ／タグ別の絞り込み
・題名・メモ・タグを横断した検索
・JSONファイルへの書き出し、読み込み
・一覧の印刷

■ ここが違います
・外部と通信しません
　入力した内容が外に出ることはありません。
　社内規程でクラウドサービスを使えない現場でもお使いいただけます。

・買い切りです
　月額費用はかかりません。

・インストールしません
　exeではなくHTMLファイルです。管理者権限も不要です。

・ライブラリに依存しません
　配布元のサービスが終了しても動き続けます。

■ 動作環境
・Google Chrome / Microsoft Edge / Firefox / Safari の最新版
・Windows / macOS / Linux
・インターネット接続は不要です（ファイルを開くだけ）

■ ⚠ データの保存場所について（大切なお願い）
入力された内容は、お使いのブラウザの中にのみ保存されます。
ブラウザの「閲覧データの削除」を行うと、データも一緒に消えます。
消えたデータは、こちらでも復元できません。

画面右上の「⇅」から「JSON で書き出す」で、
定期的にファイルへお控えいただくことをおすすめします。

■ 含まれるもの
・TaskDeck.html（本体）
・使い方マニュアル
・使用許諾契約書
・はじめにお読みください

■ サポート
BOOTHのメッセージにてお受けします。
〔平日2営業日以内〕にご返信します。

■ 返金について
デジタル商品の性質上、ご購入後の返金は原則としてお受けできません。
ただし、本ソフトウェアが動作しない事象については、
ご購入後14日以内にご連絡いただければ、修正版の提供または返金で対応します。

■ 使用許諾契約書
ダウンロードファイルに同梱しています。
ご購入前にご確認されたい場合は、メッセージにてお申し付けください。

━━━━━━━━━━━━━━━━━━━━
〔販売者名〕
━━━━━━━━━━━━━━━━━━━━
```

## プラン別の冒頭

### パーソナル

```
1台のパソコンでお使いいただけるプランです。
個人でお使いの方、まず試してみたい方向けです。
```

### ビジネス

```
5台までのパソコンでお使いいただけるプランです。
部署・チーム単位での導入に向いています。
請求書・見積書が必要な場合は、ご購入前にメッセージにてご相談ください。
```

### サイトライセンス

```
台数の制限なく、貴社内でお使いいただけるプランです。
全社導入、情報を外部に出せない現場での一括導入に向いています。
請求書・見積書が必要な場合は、ご購入前にメッセージにてご相談ください。
```

### 確定申告オプション

```
TaskDeck に確定申告用のデータ管理を追加するオプションです。
⚠ このオプション単体では動きません。TaskDeck 本体が必要です。

複式簿記（青色申告65万円控除向け）に対応しています。
・仕訳の入力
・総勘定元帳
・試算表
・損益計算書
・貸借対照表
・仕訳帳のCSV書き出し

⚠ 税額の計算・判定は行いません。帳簿を作るところまでが範囲です。

すでにTaskDeckをお持ちの方は、ご購入後にお送りする
新しいライセンスキーに入れ替えるだけでお使いになれます。
記録済みのタスクや仕訳はそのまま残ります。

キーをお送りする前でも、仕訳〔30〕件までは体験版としてお試しいただけます。
```
