# 送る文面のひな型

BOOTH で売る場合は、**BOOTH のメッセージ**にそのまま貼れます。
自分のサイトで売る場合はメールとして使ってください。

〔　〕を置き換えてお使いください。

---

## 1. 納品（購入後、キーを発行したら送る）

> 🚨 **商品説明に書いた期限（既定は1営業日）を守ってください。**
> 購入者はダウンロードを済ませて、キーを待っています。

**件名:** 【TaskDeck】ライセンスキーのお届け

```
〔お客様名〕 様

このたびは TaskDeck をご購入いただき、誠にありがとうございます。
ライセンスキーをお送りします。

■ ライセンスキー
TD1.〔ここに keygen.py issue が出力した1行を貼り付け〕

■ はじめかた
1. ダウンロードしたZIPを展開し、「TaskDeck.html」を開きます。
2. 画面右上の「ライセンス」を押します。
3. 上のキーを貼り付けて「登録する」を押します。

これで、そのままお使いいただけます。
インストールもアカウント登録も不要です。データはお客様の端末内にのみ保存され、
外部へ送信されることはありません。

※ ファイルは商品ページからいつでも再ダウンロードいただけます。
　 更新版を出した際も、同じ場所から最新版をお受け取りいただけます。

■ ご購入内容
プラン: 〔ビジネス（5台まで）〕
ライセンス名義: 〔お客様名〕
※ 名義とキーは、アプリの「ライセンス」画面でいつでもご確認いただけます。

■ ⚠ データの保存場所について（大切なお願い）
入力された内容は、お使いのブラウザの中にのみ保存されます。
ブラウザの「閲覧データの削除」を行うと、TaskDeck のデータも一緒に消えます。
消えたデータは、こちらでも復元できません。

画面右上の「⇅」から「JSON で書き出す」で、定期的にファイルへ
お控えいただくことをおすすめします。

■ この連絡は保管をお願いします
ライセンスキーの再発行には、ご購入時のお名前・注文番号が必要です。

■ サポート
ご不明な点は、このままご返信ください。
使い方は同梱の「使い方マニュアル.md」にも記載しています。

〔販売者名〕
〔サポート窓口のメールアドレス〕
```

## 2. キーが登録できないという問い合わせへの返信

```
〔お客様名〕 様

ご連絡ありがとうございます。お手数をおかけしております。
次の点をご確認いただけますでしょうか。

1. キーの前後に、余分な空白や改行が入っていないか
   → メール本文の「TD1.」から行末までを、まとめて選択してコピーしてください。
2. 途中で改行されて、2行に分かれていないか
   → 1行として貼り付ける必要があります。
3. 貼り付け先が「ライセンスキー」の欄になっているか

上記でも解決しない場合は、お手数ですがこのメールにご返信ください。
新しいキーを発行してお送りします。

〔販売者名〕
```

## 2.5 ライセンスキーを紛失したという問い合わせへの返信

> 販売者側の作業: `python3 tools/keygen.py list --find "〔お名前か注文番号〕"` で番号を調べ、
> `python3 tools/keygen.py reissue --row 〔番号〕` で作り直します。
> ⚠ 前のキーは無効になりません（アプリは通信しないため止められません）。

**件名:** Re: ライセンスキーの再発行について

```
〔お客様名〕 様

お問い合わせありがとうございます。
ご購入時の記録を確認いたしました。同じ内容でライセンスキーを再発行しております。

■ ライセンスキー
TD1.〔ここに keygen.py reissue が出力した1行を貼り付け〕

■ ご購入内容
プラン: 〔ビジネス（5台まで）〕
ライセンス名義: 〔お客様名〕
ご購入日: 〔YYYY-MM-DD〕

画面右上の「ライセンス」からこのキーを登録してください。
記録済みのタスクはそのまま残ります。

この連絡は、次回のために保管をお願いいたします。

〔販売者名〕
〔サポート窓口のメールアドレス〕
```

```
〔お客様名〕 様

ライセンスキーのお届けが遅れており、申し訳ございません。

キーの登録後も、記録済みの内容はそのまま残ります。

いましばらくお待ちください。

```

## 3. 端末を移したいという問い合わせへの返信

```
〔お客様名〕 様

お問い合わせありがとうございます。
新しい端末では、次の手順でそのままお使いいただけます。

1. これまでの端末で TaskDeck を開き、右上の「⇅」から「JSON で書き出す」を選びます。
2. できたファイルを新しい端末へお移しください。
3. 新しい端末で TaskDeck.html を開き、「⇅」→「JSON を読み込む」を選びます。
4. 右上の「ライセンス」から、同じライセンスキーを登録してください。

ご購入のプランでは〔5〕台までご利用いただけます。

〔販売者名〕
```

## 3.5 オプション（拡張）を購入されたとき

**件名:** 【TaskDeck】オプション「〔確定申告データ管理〕」のご購入ありがとうございます

```
〔お客様名〕 様

このたびはオプションをご購入いただき、ありがとうございます。
拡張パッケージと、新しいライセンスキーをお送りします。

■ 拡張パッケージのダウンロード
〔ダウンロードURL〕

■ 新しいライセンスキー（これまでのキーと入れ替えてください）
TD1.〔--ext を付けて発行したキーを貼り付け〕

■ 入れかた
1. TaskDeck.html を開き、画面右上の「⊞」を押します。
2.「パッケージのファイルを選ぶ」から、ダウンロードした .tdpkg を選びます。
3. 画面右上の「ライセンス」を押し、上の新しいキーに貼り替えて「登録する」を押します。
4. 左のメニューに項目が増えていれば完了です。

これまでのタスクはそのまま残ります。データが消えることはありません。

■ ご注意
拡張が保存したデータは、本体の「JSON で書き出す」には含まれません。
拡張ごとの書き出し（CSV）を別途お使いください。

〔販売者名〕
〔サポート窓口のメールアドレス〕
```
