# 販売のはじめかた（販売者向け）

自社サイトでの直販を想定した手順です。上から順にやれば、その日のうちに売り始められます。
所要時間はおよそ 1〜2 時間です。

---

## 0. 何がどこにあるか

```
taskdeck/
├── app/taskdeck.html        製品そのもの（これを売ります）
├── extensions/tax/          オプション「確定申告データ管理」のソース
├── landing/index.html       販売ページ（そのままサイトに置けます）
├── docs/
│   ├── MANUAL.md            購入者向けの使い方（ZIP に同梱されます）
│   ├── README-FOR-BUYER.txt 開封時に最初に読んでもらう案内
│   ├── SELLING-GUIDE.md     この文書
│   └── MAIL-TEMPLATES.md    納品・サポートのメール文面
├── legal/                   使用許諾契約書・特商法表記・プライバシーポリシー
├── tools/
│   ├── keygen.py            ライセンスキーの発行
│   ├── pkg.py               拡張パッケージの署名
│   └── build.sh             配布用 ZIP の作成（本体＋拡張）
└── keys/                    秘密鍵と発行台帳（自分だけが持つ。公開厳禁）
```

---

## 1. 鍵を作る（最初に一度だけ）

```bash
python3 taskdeck/tools/keygen.py init
```

これで次の 2 つが起きます。

- `taskdeck/keys/private.json` に**秘密鍵**ができる
- `app/taskdeck.html` に**公開鍵**が埋め込まれる

> **秘密鍵は必ずバックアップしてください。**
> 失うと、以後キーを発行できなくなります。作り直すと、それまでに売ったキーが
> すべて無効になります（購入者の手元で「正しくありません」と出ます）。
> `keys/` は `.gitignore` によって Git に入りません。パスワード管理ソフトや
> 暗号化した外部メディアなど、リポジトリの外に保管してください。

公開鍵は配布物に入りますが、これは公開して問題ありません。
公開鍵だけではキーを作れないため、配布物を解析されてもキーは偽造されません。

---

## 2. 販売ページを自分のものにする

`landing/index.html` をエディタで開き、次を差し替えます。すべて〔　〕で囲ってあります。

| 差し替える箇所 | 例 |
|---|---|
| 〔販売者名〕 | 会社名・屋号 |
| 〔サポート窓口のメールアドレス〕 | support@example.com |
| 〔決済リンク: パーソナル〕など | 決済サービスで作った購入URL |
| 〔特商法表記のURL〕〔プライバシーポリシーのURL〕 | 掲載したページのURL |
| 価格 | ページ内の「¥3,800」などの表記（3 か所のプラン欄） |

スクリーンショット（`landing/assets/`）は自分の画面に差し替えても構いません。

## 3. 決済リンクを用意する

Stripe を使う場合の最短経路です（PayPal・Paddle・BOOTH などでも考え方は同じです）。

1. Stripe にログインし、**商品カタログ**でプランごとに商品を作る（買い切りなので「一回限りの支払い」）。
2. それぞれに **Payment Link** を作る。
3. 支払い後の画面で「購入完了ページ」を指定し、購入者にメールで届く旨を書いておく。
4. できた URL を `landing/index.html` の〔決済リンク: 〜〕へ貼る。

決済完了の通知メールを受け取ったら、次の 4 章でキーを発行します。
（自動化したくなったら、決済サービスの Webhook から `keygen.py issue` を呼ぶ形にできます。
最初は手作業で十分です。1 件あたり 1 分もかかりません。）

## 4. 注文が入ったらキーを発行する

```bash
python3 taskdeck/tools/keygen.py issue --name "株式会社サンプル" --plan business --seats 5 --note "注文番号 1234"
```

- `--plan` は `personal` / `business` / `site`
- `--seats` は使用できる台数
- 期間限定にするなら `--expires 2027-08-31`

発行したキーは `keys/issued.csv` に控えが残ります。
出力された `TD1.〜` の 1 行を、購入者へのメールに貼り付けて送ります。
文面は `docs/MAIL-TEMPLATES.md` にあります。

発行したキーが有効かどうかは、いつでも確認できます。

```bash
python3 taskdeck/tools/keygen.py verify "TD1.…"
```

## 4.5 オプション（拡張）を売る

本体とは別に、拡張パッケージを単品で売れます。手順は本体とほとんど同じです。

```bash
bash taskdeck/tools/build.sh
# → dist/taskdeck-1.0.0.zip        本体
# → dist/taskdeck-tax-1.0.0.zip    オプション「確定申告データ管理」
```

注文が入ったら、その購入者の**新しいキーを発行し直します**。

```bash
python3 taskdeck/tools/keygen.py issue --name "株式会社サンプル" --plan business --seats 5 --ext tax
```

購入者は、届いたキーを「ライセンス」画面で入れ替えるだけです。
記録済みのタスクや仕訳はそのまま残ります。

| 場面 | 発行するキー |
|---|---|
| 本体だけ | `--ext` なし |
| 本体＋確定申告 | `--ext tax` |
| あとから確定申告を追加購入 | 同じ購入者に `--ext tax` を付けて再発行 |

拡張は、キーが無くても評価として動きます（確定申告なら仕訳 30 件まで）。
「まず入れてもらって、続けたくなったら買ってもらう」流れを作れます。

拡張を新しく作るときは `extensions/` に置いて `python3 taskdeck/tools/pkg.py build extensions/<id>` を実行します。
書き方は `taskdeck-docs/docs/開発/拡張の作り方.md` にまとめてあります。

## 5. 配布用 ZIP を作る

```bash
bash taskdeck/tools/build.sh
```

`taskdeck/dist/taskdeck-1.0.0.zip` ができます。中身はアプリ本体・マニュアル・
使用許諾契約書・はじめにお読みくださいの 4 点です。
公開鍵が未設定のときや、テストが通らないときは、途中で止まって配布物を作りません。

この ZIP を、ダウンロード用の場所（自社サーバー、S3、決済サービスのファイル配信など）に置き、
その URL を購入者に伝えます。

## 6. 法務ページを掲載する

`legal/` の 3 つを、自分の情報に置き換えてサイトに掲載します。

- **特定商取引法に基づく表記** … 日本国内で有料販売するなら必須です。販売ページからリンクします。
- **プライバシーポリシー** … 決済でメールアドレスを扱うため必要です。
- **使用許諾契約書** … ZIP に同梱され、販売ページからもリンクします。

## 7. 売る前の最終確認

- [ ] `keygen.py init` を実行し、秘密鍵をリポジトリの外にバックアップした
- [ ] 発行したキーが、実際に `TaskDeck.html` で登録できることを自分で確かめた
- [ ] `landing/index.html` の〔　〕をすべて置き換えた（`grep 〔 landing/index.html` で確認）
- [ ] 決済リンクを実際に押して、購入画面まで進めることを確かめた
- [ ] 特商法表記・プライバシーポリシー・使用許諾契約書を掲載し、リンクが切れていない
- [ ] ダウンロードURLから ZIP が落ちてきて、中の HTML が開くことを確かめた
- [ ] 納品メールの文面に、ダウンロードURL・キー・サポート窓口が入っている
- [ ] オプションを売るなら、拡張つきのキーで実際に制限が外れることを確かめた

## 価格の考えかた

買い切りのデスクトップ向けツールとしては、次のあたりが置きやすい値段です。

| プラン | 目安 | 想定 |
|---|---|---|
| パーソナル（1台） | 3,000〜4,000円 | 個人。月額サービスを避けたい層 |
| 確定申告オプション | 6,000〜8,000円 | 本体購入者への追加販売。単価を上げやすい |
| ビジネス（5台） | 12,000〜15,000円 | 小さなチーム。部署単位の購入 |
| サイトライセンス | 40,000〜60,000円 | 法人一括。情報を外に出せない現場 |

この製品の強みは「サーバーに置かない・通信しない・買い切り」です。
月額のクラウド型と機能数で競うのではなく、
**外部にデータを預けられない現場**（士業・医療・自治体・製造業の現場など）に向けて説明すると通りやすくなります。

## 値上げ・改訂をするとき

- 価格は `landing/index.html` の 3 か所を直すだけです。
- アプリを直したら `VERSION=1.1.0 bash taskdeck/tools/build.sh` で新しい ZIP を作り、
  既存のお客様には `keys/issued.csv` のメール控えをもとに案内します。
- 公開鍵は変えないでください。変えると発行済みのキーが無効になります。
