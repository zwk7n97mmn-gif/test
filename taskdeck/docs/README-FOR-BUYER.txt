TaskDeck をご購入いただきありがとうございます。

■ すぐに使いはじめる
  1. このフォルダの「TaskDeck.html」をダブルクリックしてください。
     いつものブラウザ（Chrome / Edge / Safari / Firefox）で開きます。
  2. それだけです。インストールも、アカウント登録も、通信も必要ありません。

■ ライセンスキーの登録
  1. 画面右上の「ライセンス」を押します。
  2. ご購入時のメールに書かれているキー（TD1. で始まる長い文字列）を貼り付けます。
  3. 「登録する」を押すと、評価版の 30 件の上限がなくなります。

  ※ キーはこの端末のブラウザにだけ保存されます。認証のための通信は行いません。
  ※ 端末を移したときは、同じキーをもう一度登録してください。

■ データの保管場所
  タスクはお使いのブラウザの中（ローカルストレージ）に保存されます。
  外部のサーバーへは一切送信されません。

  次の場合はデータが消えます。ご注意ください。
    ・ブラウザの「閲覧データの削除」でサイトデータを消したとき
    ・プライベートウィンドウで開いて閉じたとき
    ・別のブラウザや別の端末で開いたとき（データは共有されません）

  画面右上の「⇅」から JSON ファイルとして書き出せます。
  大事な内容は、ときどき書き出して保管してください。
