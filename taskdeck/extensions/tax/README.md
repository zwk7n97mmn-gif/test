# 確定申告データ管理（TaskDeck 拡張）

個人事業主の青色申告を想定した帳簿です。複式簿記で仕訳を記録すると、
総勘定元帳・試算表・損益計算書・貸借対照表の集計まで自動で出ます。

タスク管理と同じく、データはこの端末のブラウザの中だけに保存され、外部へは送信されません。

## 入れかた

1. TaskDeck.html を開く
2. 右上の **⊞（拡張）** を押す
3. 「パッケージのファイルを選ぶ」から `tax-1.0.0.tdpkg` を選ぶ
4. 左のメニューに「確定申告」が増えます

評価のあいだは仕訳を 30 件まで登録できます。
拡張つきのライセンスキーを「ライセンス」画面で登録すると、上限がなくなります。

## 6 つの画面

| 画面 | 何をするところ |
|---|---|
| 仕訳の入力 | 日付・摘要・勘定科目・金額を入れて登録します。借方と貸方が合わないと登録できません |
| 仕訳帳 | その年度に登録した仕訳を日付順に並べます |
| 総勘定元帳 | 勘定科目ごとの出入りと残高を追えます |
| 試算表 | 科目ごとの借方合計・貸方合計・残高。合計が一致しているかを確かめます |
| 決算のまとめ | 収益・経費・所得と、損益計算書／貸借対照表の内訳 |
| 設定 | 屋号の登録と、勘定科目の追加・削除 |

## よく使う仕訳の形

| 場面 | 借方 | 貸方 |
|---|---|---|
| 売上を請求した（未入金） | 売掛金 | 売上高 |
| 請求した分が入金された | 普通預金 | 売掛金 |
| その場で現金売上 | 現金 | 売上高 |
| 経費をカード・口座で払った | （各経費科目） | 普通預金 |
| 経費を私費で立て替えた | （各経費科目） | 事業主借 |
| 事業のお金を私用に使った | 事業主貸 | 普通預金 |
| 外注費が未払い | 外注工賃 | 未払金 |

## タスクとのつながり

タスクの詳細を開くと「この仕事の記帳」欄があります。
**このタスクから仕訳を作る** を押すと、その仕事名で仕訳の下書きができます
（借方「売掛金」／貸方「売上高」）。金額を入れて登録してください。

記帳済みの仕訳は、そのタスクの詳細から一覧で確認できます。
「この案件、請求したっけ？」を、タスクの画面から確かめられます。

## 書き出し

右上の **⇅** →「拡張の書き出し」から次の 2 つが出せます。

- **仕訳帳CSV** … 1 行 1 明細。会計ソフトへの取り込みや、税理士への提出に
- **試算表CSV** … 科目ごとの集計。決算書への転記に

いずれも Excel でそのまま開ける形式（BOM 付き UTF-8）です。

## ご注意

- この拡張は**帳簿づけと集計**を行うもので、税額の計算や申告書の作成は行いません。
- 減価償却・家事按分・棚卸・消費税の処理は含まれません。決算のまとめに出るのは、入力した仕訳をそのまま集計した金額です。
- 申告の内容については、最終的に税務署または税理士にご確認ください。
- 拡張を取り外すと、記帳したデータも消えます。取り外す前に CSV で書き出してください。
