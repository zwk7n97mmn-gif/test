# Motion Muse

**スマホだけで完結する 3D ダンス動画メーカー。**

音源を解析し、**動画から抽出した「動き」だけ**を 3D キャラクターに適用して、
縦型ショート動画を作ります。サーバー不要・完全ローカル動作の PWA です。

- **スマホ完結** — 撮影（カメラ）→ 解析 → 3D 生成 → 書き出し → 共有までブラウザ内で完了
- **3D アバター** — VRM / glTF のモデルを読み込んで動かせます（実写寄りの見た目にしたい場合はこちら）
- **内蔵 3D キャラクター** — アバターを用意しなくても使える。体型・髪型・服装・肌の色などを変更可能
- **アニメ調 / アイドル衣装** — 大きな瞳・星のハイライト・ツインテール・プリーツ衣装をワンタップで適用
- **音源解析** — BPM / ビート位置 / 楽曲構成（サビ）を実測で検出
- **モーション抽出** — 動画中の人物の 3D 関節位置のみを取り出し、体格に依存しない形式へ正規化
- **ビート同期演出** — 検出したビートに合わせたカメラのズーム・ライティング・パーティクル
- **オフライン対応** — Service Worker により、2 回目以降は電波が無くても動作

## セットアップ

```bash
npm install
npm run setup     # 姿勢推定モデル + PWAアイコンを生成（初回のみ・要ネットワーク）
npm run dev       # http://localhost:5173
```

`npm run setup` はモデル (.task 約 15MB) と MediaPipe の WASM をローカルに配置し、
PWA アイコンを生成します。以降はオフラインでも動作し、実行時に外部 CDN へアクセスしません。

スマートフォンから試すには、同一ネットワーク上で `npm run dev -- --host` を実行して
表示された URL を開くか、`npm run build && npm run preview` の結果を HTTPS で配信してください
（カメラと Service Worker には HTTPS または localhost が必要です）。

## 使い方（スマホ）

1. ホーム画面に追加（アプリ内のバナー、または共有 →「ホーム画面に追加」）
2. **音源** — 曲を選ぶと BPM・サビが自動検出されます
3. **モーション** — 「カメラで撮る」で踊りを撮影、または手持ちの動画を選択して抽出
4. **容姿** — VRM / glTF アバターを読み込むか、内蔵キャラクターの体型・髪型・服装を調整
   （どちらを選んでも、動きは 1 フレームも変わりません）
5. **演出** — 背景・エフェクト・テロップ・ビート同期を調整
6. **書き出し** — 動画を生成し、そのまま共有シートから SNS へ

キーボード操作にも対応しています（タブ間は `←` `→`、スキップリンクあり）。

## 見た目のクオリティについて

内蔵キャラクターはスキンメッシュの 3D キャラクターで、体型・髪型・服装・肌の色を
アプリ内だけで変更できます。**造形は「ナチュラル」と「アニメ調」から選べ**、
アニメ調では瞳が大きくなり、星形ハイライト・髪飾り・毛先のグラデーション・
アイドル衣装（プリーツスカート + 長手袋 + ロングブーツ）を組み合わせられます。
容姿タブの「✨ アニメ調アイドルにする」で一括適用してから個別に調整するのが早道です。

ただしプログラムで組み立てているため、
**写真のような実写クオリティにはなりません**（きれいなスタイライズド 3D、が上限です）。

なお、特定の作品のキャラクターを複製する機能はありません。用意しているのは
ジャンルとして一般的なパーツの組み合わせで、色・髪型・衣装はすべて個別に変更できます。

さらに作り込まれた見た目にしたい場合は、任意で VRM / glTF のアバターを読み込めます
（**必須ではありません**）。本ツールが与えるのは骨の向きだけなので、
モデル本来の造形・質感・衣装がそのまま出ます。

なお、**手元の写真に写っている人物そのものを動かす**機能はありません
（拡散モデルによる動画生成が必要でブラウザ内では動作せず、実在人物のなりすましにも直結するため）。

## 公開する（無料・PC不要）

`.github/workflows/deploy.yml` を同梱しています。

1. GitHub にこのリポジトリを置く
2. Settings → Pages → Source を **GitHub Actions** にする
3. main に push（または Actions から手動実行）

ビルド・テスト・モデル取得まで自動で走り、`https://<ユーザー名>.github.io/<リポジトリ名>/` で
公開されます。以降はスマホでその URL を開き、ホーム画面に追加するだけで使えます。

## 重要な前提

- 本ツールは **TikTok を含む外部サービスから音源・動画を自動取得しません**。各サービスの
  利用規約に反するスクレイピングを行わない方針のため、素材はご自身が利用権を持つ
  ファイルを使ってください。トレンド一覧は公式画面からエクスポートした CSV / JSON を取り込めます。
- 元動画から取り出すのは**関節座標のみ**です。元の映像・人物の容姿は保存も出力もされません。
  ただし振り付けそのものに権利が及ぶ場合があるため、公開前に権利関係をご確認ください。

## 動作環境

- **推奨**: iOS 16 以降の Safari / Android 10 以降の Chrome
- WebGL2（3D 描画）、IndexedDB（保存）が必須です
- 書き出しには `MediaRecorder` と `canvas.captureStream` が必要です
  （未対応の場合は書き出しボタンが無効化され、理由が表示されます）
- PC ブラウザでも動作します（スマホ幅で中央に表示されます）

詳細な設計は [docs/DESIGN.md](docs/DESIGN.md)、受け入れ基準と検証結果は
[docs/ACCEPTANCE.md](docs/ACCEPTANCE.md) を参照してください。
