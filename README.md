# Motion Muse

音源を解析し、**動画から抽出した「動き」だけ**をオリジナルキャラクターに適用して、
縦型ショート動画を制作するブラウザツールです。サーバー不要・完全ローカル動作。

- **音源解析** — BPM / ビート位置 / 楽曲構成（サビ）を実測で検出
- **モーション抽出** — 動画中の人物の関節位置のみを取り出し、体格に依存しない形式へ正規化
- **容姿の差し替え** — 髪型・目・衣装・色・頭身などを変更（動きは 1 フレームも変わらない）
- **ビート同期演出** — 検出したビートに合わせたズーム・パーティクル・背景の明滅
- **書き出し** — 音声付き動画（MP4 / WebM）としてダウンロード

## セットアップ

```bash
npm install
npm run fetch:models   # 姿勢推定の WASM とモデルを public/ へ配置（初回のみ・要ネットワーク）
npm run dev            # http://localhost:5173
```

`fetch:models` はモデル (.task 約 15MB) と MediaPipe の WASM をローカルに配置します。
これ以降はオフラインでも動作し、実行時に外部 CDN へアクセスしません。

## コマンド

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバー |
| `npm run build` | 本番ビルド（型チェック込み） |
| `npm test` | ユニットテスト（84 件） |

| `npm run check:visual` | 実ブラウザで描画を確認しスクリーンショットを保存 |

## 使い方

1. **音源** タブで音声ファイルを読み込む → BPM・サビが自動検出されます
2. **モーション** タブで動画を読み込み、区間を選んで抽出
3. **容姿** タブでキャラクターの見た目を調整
4. **演出** タブで背景・エフェクト・テロップ・同期設定
5. **書き出し** タブで動画を保存

キーボード操作: `Space` 再生/一時停止、タブ間は `←` `→`、スキップリンクで本文へ直接移動できます。

## 重要な前提

- 本ツールは **TikTok を含む外部サービスから音源・動画を自動取得しません**。各サービスの
  利用規約に反するスクレイピングを行わない方針のため、素材はご自身が利用権を持つ
  ローカルファイルを読み込んでください。トレンド一覧は公式画面からエクスポートした
  CSV / JSON を取り込めます。
- 元動画から取り出すのは**関節座標のみ**です。元の映像・人物の容姿は保存も出力もされません。
  ただし振り付けそのものに権利が及ぶ場合があるため、公開前に権利関係をご確認ください。

## 動作環境

Chrome / Edge / Firefox / Safari の最新版。書き出しには `MediaRecorder` と
`canvas.captureStream` が必要です（未対応の場合は書き出しボタンが無効化され、理由が表示されます）。

詳細な設計は [docs/DESIGN.md](docs/DESIGN.md)、受け入れ基準と検証結果は
[docs/ACCEPTANCE.md](docs/ACCEPTANCE.md) を参照してください。
