# 🎬 Kirinuki Studio

ブラウザだけで完結する動画編集ツール。
素材を**解析**して、**字幕・カット編集・音声処理**を自動で付与し、**サムネイル**と**SNS キャプション**まで作成します。

- ビルド不要・**依存パッケージゼロ**（素の ES Modules）
- 動画はブラウザ内でのみ処理され、**外部に送信されません**（外部 STT を明示的に設定した場合を除く）
- 設計書: [`docs/DESIGN.md`](docs/DESIGN.md) ／ 手動テスト手順: [`docs/QA.md`](docs/QA.md)

```bash
npm start      # http://localhost:8080 で起動
npm test       # 131 件の単体テスト（node --test / 依存ゼロ）
```

> 動作要件: Chrome / Edge 116+ または Safari 17+。`file://` では動きません（ES Modules のため）。

---

## できること

| 機能 | 内容 |
|---|---|
| **素材解析** | シーン切替点・発話区間・無音区間・ラウドネス・フレーム品質を自動抽出しタイムラインに可視化 |
| **字幕の自動付与** | 発話区間からタイムコードを自動生成。STT を設定すればテキストまで自動（下記参照） |
| **編集の自動付与** | 無音の自動カット（または倍速化）。前後パディング・最小クリップ長を調整可能 |
| **音声の自動付与** | ラウドネス正規化・BGM の自動ダッキング・フェードイン/アウト |
| **サムネイル作成** | 品質スコア上位のフレームを自動抽出 → テキストを載せて 1280×720 PNG で書き出し |
| **キャプション作成** | 字幕・尺・シーンから X / Instagram / YouTube / TikTok 向けの投稿文を生成（文字数上限を厳守） |
| **書き出し** | 字幕焼き込み動画・SRT・WebVTT・サムネイル PNG・プロジェクト JSON |

---

## 使い方

1. **素材を読み込む** — 画面左へ動画をドラッグ＆ドロップ（MP4 / WebM / MOV）。
2. **解析が自動で走る** — 完了後、「自動処理」ダイアログで字幕・カット・音声を一括適用できます。
3. **字幕を仕上げる** — 「字幕」タブで表を編集。SRT / VTT の取り込みも可能です。
4. **サムネイル・キャプション** — 各タブで生成・調整。
5. **書き出す** — 「書き出し」タブから動画・字幕・プロジェクトを保存。

### キーボード操作

| キー | 動作 |
|---|---|
| `Space` | 再生 / 一時停止 |
| `←` `→` | 1 フレーム移動（`Shift` で 1 秒） |
| `Home` `End` | 先頭 / 末尾へ |
| `S` | 再生位置でクリップを分割 |
| `Ctrl + Z` / `Ctrl + Shift + Z` | 元に戻す / やり直す |
| `1` – `7` | パネル切替 |
| `?` | ショートカット一覧 |

タイムラインはフォーカスすると矢印キーで操作できます（`role="slider"`）。
すべての操作がキーボードのみで完結し、主要な文字色はコントラスト比 4.5:1 以上を機械検証しています。

## 文字起こし（STT）について

ブラウザ単体では音声認識ができません（Web Speech API はマイク入力専用で、ファイルを渡せません）。
そのため 2 つの方法を用意しています。**存在しないテキストを creative に埋めることはしません。**

| 方法 | 通信 | 生成される内容 |
|---|---|---|
| **発話区間のみ**（既定） | なし | 字幕の**開始・終了時刻のみ**。テキストは「要入力」バッジ付きの空欄 |
| **外部 STT** | あり | タイムコード＋**テキスト**（OpenAI 互換 `/v1/audio/transcriptions`） |

外部 STT は「素材・解析」タブで設定します。API キーは**タブのメモリ上にのみ保持**し、保存も送信先以外への送出も行いません。
この方法を選ぶと音声データが設定先へ送信される点にご注意ください。

## 制約

1. 動画の書き出しは `MediaRecorder` による**実時間レンダリング**です（10 分の動画は約 10 分）。
2. 出力コンテナは環境依存で **MP4 または WebM**（起動時に判定し、書き出しパネルに実際の形式を表示します）。
3. `decodeAudioData` が対応しないコーデックの素材は、音声解析を諦めて**映像のみモード**へ縮退します。
4. プロジェクトの自動保存に**動画ファイル本体は含まれません**。復元後は同じ動画を選び直してください。

## 構成

```
index.html
src/
  core/     解析・編集判断・整形（DOM 非依存の純粋関数 = テスト対象）
  media/    WebAudio / Canvas / MediaRecorder（副作用）
  ui/       ビュー
test/       node --test（依存ゼロ）
docs/       設計書・QA 手順
```

プレビューと書き出しは同じ描画・音声プラン生成コードを共有しているため、**画面で見たものがそのまま出力されます**。
