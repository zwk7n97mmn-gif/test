## <a id="hajimeni"></a>🔰はじめに【👀必読】

### ❓ここには何が置いてある？

**自分たちで作った道具の説明書**です。作った物そのもの（ソース）は別のリポジトリにあり、
ここには**説明だけ**を置きます。ソースと説明が同じ場所にあると、
どちらが正しいのか分からなくなるためです。

- [このwikiの読み方](はじめに/このwikiの読み方.md) … どこから読むか。ページの構成。
- [用語集](はじめに/用語集.md) … このwikiで使う言葉の意味。

### ❗❗開発で意識すること❗❗

> 🚨 **機械で守れることは機械で守る。**<br>
> 人が気をつけるルールは必ず破られます。破られたと**すぐ分かる**ようにするのが検査です。

- ページを足したら **README に登録する**。登録していないページは検査で落ちます。
- 決まりごとを変えたら、**人向け（`wikiの編集方法/ページの書き方.md`）と
  機械向け（`CLAUDE.md`）を同じコミットで**直す。
- 迷ったら [ページの書き方](wikiの編集方法/ページの書き方.md) を読む。
